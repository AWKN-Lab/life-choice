## 3. 写入规则

### 3.1 决策记录（01-decisions/）

- 文件名格式：`YYYY-MM-DD_简短标题.md`
- frontmatter 必含：`type: decision, title, created, tags, status`
- 内容包含：背景、选项、选择理由、预计后果、关联文件、复盘点
- 用 `[[wikilinks]]` 关联相关的目标/会话

### 3.2 经验规则（02-evolution/）

- 文件名：`learned-rules.md`（汇总）+ `E编号_标题.md`（单条详细）
- E编号：子项目独立编号，从 E90/E62/E277 起步（沿用主目录编号但内容独立）
- 同一模式出现 ≥3 次 → 提升为规则
- 每条规则含：场景、规则、检查方式、触发词、来源

### 3.3 会话记忆（03-sessions/）

- 目录格式：`YYYY-MM-DD/session-NNN.md`
- 会话编号按日期内递增（session-001, session-002...）
- 内容包含：目标、关键决策、踩坑、下一步

### 3.4 目标（00-goals/）

- 每个目标一个 `.md` 文件，`type: goal`
- 活跃的用 `status: active`，完成的用 `status: completed`
- 用 `[[wikilinks]]` 关联该目标下的决策、会话、复盘

---

## 4. 不复制主目录内容的理由

1. **避免重复**：主目录已有完整治理规则，子项目无需重复
2. **聚焦**：子项目记忆系统聚焦于"人生决策宗师"项目自身的决策与经验
3. **独立性**：子项目可独立迁移/归档，不依赖主目录
4. **治理沿用**：子项目治理规则沿用主目录 `00-memory-control/`，无需本地副本
