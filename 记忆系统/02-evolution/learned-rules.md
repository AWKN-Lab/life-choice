# Learned Rules — 人生决策宗师子项目经验规则

> 子项目独立沉淀的经验规则，与 AWKN-Lab 主目录规则不冲突。
> 主目录规则见 `../../../../记忆系统/02-evolution/learned-rules.md`
> 同一模式出现 ≥3 次 → 提升为本规则。

## 当前规则

### E90 完成声明诚实门禁（2026-07-06 沉淀）

- **场景**：commit `ed565f2e` 的 commit message 完整描述了取证结论，但实际写入的文件 `P0-1-Git工作区清理-书本提取取证-20260706.md` 是空文件
- **规则**：commit message 声称完成的内容必须有对应文件落盘（文件大小 > 0）
- **检查**：commit 前用 `git show --stat HEAD` 验证文件大小 > 0
- **触发词**：commit 完成声明、空文件、E90

### E62 对标假设验证门禁（2026-07-09 沉淀）

- **场景**：原 P0-1 报告推测"1135 vs 1155 差 20 = missing 元数据缺失"，Phase B 用 `_diff_books.py` 脚本做集合差验证后发现根因是 ledger 20 条 title 重复记录
- **规则**：任何"差异根因推测"必须用脚本做集合差验证，不能停留在文字推测
- **检查**：差异复核必须有脚本输出 + 数字闭环（1135 + 20 = 1155）
- **触发词**：差异根因、集合差、假设验证、E62

### E277 完成定义前置（2026-07-10 沉淀）

- **场景**：原计划 Phase D 假设"配置 HF_ENDPOINT=hf-mirror.com 即可恢复 BGE"，实际 curl 验证发现 huggingface.co 和 hf-mirror.com 都不可达
- **规则**：任何"假设可达"的外部依赖必须先 curl 验证，不能基于假设制定计划
- **检查**：网络依赖类任务必须有 curl 输出作为前置证据
- **触发词**：假设可达、HF_ENDPOINT、网络依赖、E277
