## 3. 关键设计决策

### D1: 开关式迁移（向后兼容）
- `USE_UNIFIED_STATE_MACHINE=1` 控制是否启用 UnifiedState（默认关闭）
- `MULTI_TURN_GRAY_PERCENT` 控制灰度流量百分比
- `LLM_ROUTER_ENABLED=1` 控制是否启用智能 Provider 路由（默认关闭）
- 所有新功能默认关闭，可通过 env 开启

### D2: 轻量级 Node.js Embedding
- 不引入 ONNX/transformers.js 等重依赖
- 采用 char-bigram + md5 hash 投影 + 256维 + L2归一化
- 参考 Python TfidfCharBigramEmbedder 简化版
- 风险：召回精度低于真模型，但满足 MVP 阶段需求

### D3: 向量+关键词混合检索
- 向量权重 0.7 + 关键词权重 0.3
- 归一化到 0-1 后加权
- 按 text 前 40 字符去重，保留高分项
- 失败时降级为纯关键词检索

### D4: 记忆遗忘三策略
- 清理：`expiresAt < now` → 删除
- 衰减：`>30天` → `weight *= 0.8`
- 归档：`>90天` → `weight = 0.1`
- 定时任务每 24h 跑一次（env 可配 `MEMORY_FORGET_INTERVAL_MS`）

### D5: 智能 Provider 路由策略
- 高复杂度任务（取名/深度推演）→ minimax（长上下文 + reasoning_split）
- VIP 用户推理型 → minimax（更高质量）
- clarify 追问 → sensenova（短回复，便宜）
- 其他 → defaultProvider
- minimax 不可用时降级到 default

### D6: G4 清洗规则
- 短标题（< 4 字符）：派生自 description / source_sha / `未命名书籍-{id}`
- 重复标题：保留 id 最小的一本，其余改为 `{title}（副本-{id}）`
- 不动 passages / chapters / cases / FTS 索引（book_id 关系不变）
