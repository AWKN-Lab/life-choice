- 服务器磁盘: `/dev/vda3 40G 35G 2.9G 93%` —— 仅 2.9GB 可用
- 服务器内存: `Mem 1871 1387 88` —— 仅 88MB free, 483MB available
- 服务器无 `/opt/awkn-life/models/` 目录
- 本地 HF cache: 仅 `bge-small-zh-v1.5`(约 100MB),无 `bge-large-zh`

### 资源需求估算
- BGE-M3 模型: 1.3GB(超出服务器可用磁盘 2.9GB 的 45%)
- v3 embeddings: 309355 × 1024 × 4 bytes = 1.2GB(超出服务器可用磁盘 2.9GB 的 41%)
- BGE-M3 推理内存: 约 2GB(超出服务器可用内存 483MB)
- 本地生成 v3 embeddings: 309355 × 50ms = 4.3 小时(超出 10 分钟执行单元)

### 决策
- **延后到 v0.2**: 服务器资源不足,无法部署 BGE-M3
- 当前 TF-IDF precision@10=0.917, recall@10=0.473 已满足业务需求
- 建议待服务器扩容或本地 GPU 可用后再启动 P3
