## 关键发现与经验

### 1. Git配置
- **发现**：SSH key认证成功但对AWKN-Lab/Mr.Mont无读写权限
- **解决**：保持HTTPS+token方式（token有组织权限）
- **后续**：需要在Mr.Mont仓库添加正确的Deploy Key

### 2. GitHub Actions billing问题
- **发现**：组织账户billing失败导致Actions无法启动
- **影响**：不影响当前手动SSH部署流程
- **建议**：禁用Actions或修复billing

### 3. nest build资源拷贝问题
- **发现**：nest build默认只编译.ts，不拷贝.md/.json等非JS资源
- **影响**：每次部署都会丢失prompts/data等资源目录
- **临时解决**：从dist.old恢复缺失资源
- **长期方案**：在nest-cli.json配置assets或用postbuild脚本

### 4. P0装甲触发链路
- **发现**：P0装甲在异步队列的deep_consult模式触发，不在同步quick_read路径
- **触发条件**：EVIDENCE_PACKAGE_ENABLED=true + chartSnapshot + 3服务注入
- **当前命中规则数**：0条（规则匹配逻辑可优化，非阻塞）

### 5. life_stage注入条件
- **发现**：life_stage在L2成功路径注入，L1 fallback时不注入
- **影响**：L2超时时用户看不到life_stage卡片（符合降级设计）
- **根因**：L2超时（150s）+ 5层校验失败
