## 4. 接口文档

### 4.1 `GET /health`

| 项 | 内容 |
|---|---|
| 方法 | GET |
| 鉴权 | 无（内网调用） |
| 用途 | 健康检查 + 数据规模 |
| 响应字段 | `status` / `version` / `bookCount` / `passageCount` / `loadedItems` / `bySystem` |

**示例响应**：
```json
{
  "status": "ok",
  "version": "2026-05-v1",
  "bookCount": 1126,
  "passageCount": 357359,
  "loadedItems": 357359,
  "bySystem": {
    "bazi": 51502, "ziwei": 77300, "qimen": 26739,
    "liuren": 16799, "liuyao": 30111, "meihua": 2760,
    "zhouyi": 5989, "fengshui": 1973, "quming": 1484,
    "xiangshu": 2550, "daoism": 2141, "other": 136291,
    "yuyan": 1720
  }
}
```

### 4.2 `POST /retrieve`

| 项 | 内容 |
|---|---|
| 方法 | POST |
| 鉴权 | 无 |
| 请求体 | `routeType: str` / `question: str` / `evidenceTags: List[str]` / `limit: int=6` |
| 响应字段 | `items: List[{sourceId, title, text, score}]` |

**示例请求**：
```bash
curl -X POST http://127.0.0.1:8701/retrieve \
  -H "Content-Type: application/json" \
  -d '{"routeType":"bazi","question":"日主身弱如何取用神","limit":6}'
```

### 4.3 `POST /embed_search`

| 项 | 内容 |
|---|---|
| 方法 | POST |
| 鉴权 | 无 |
| 请求体 | `question: str` / `systemType: Optional[str]` / `limit: int=6` |
| 响应字段 | `items: List[{sourceId, title, text, score}]` |
| 算法 | TF-IDF char-bigram + numpy cosine |

### 4.4 `POST /hybrid_search`

| 项 | 内容 |
|---|---|
| 方法 | POST |
| 鉴权 | 无 |
| 请求体 | `routeType: str` / `question: str` / `evidenceTags: List[str]` / `limit: int=6` / `vectorWeight: float=0.7` / `keywordWeight: float=0.3` |
| 响应字段 | `items: List[{sourceId, title, text, score}]` |
| 算法 | 向量 Top-K ∪ 关键词 Top-K → 重排去重 |

### 4.5 错误码

| 码 | 含义 | 处理 |
|---|---|---|
| 200 | 成功 | - |
| 422 | 请求体校验失败 | 检查字段类型 |
| 500 | 内部错误 | 看 knowledge-service 日志 |
