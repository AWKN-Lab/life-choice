## 6. 回滚方案

### 6.1 回滚决策树

```
任一Step失败
├── Step 1-5（第一闸）失败 → 回滚到当前生产状态（删除.git、恢复package-lock）
├── Step 6-10（第二闸）失败 → 回滚代码修改（git checkout），不影响生产
├── Step 11-13（第三闸）失败 → 回滚K线修改（git checkout），不影响生产
└── Step 14-16（第四闸）失败
    ├── push失败 → git reset --soft HEAD~4，不部署
    ├── 部署后5件套失败 → 回滚dist.old + 删除EVIDENCE_PACKAGE_ENABLED
    └── UC1冒烟失败 → 关闭EVIDENCE_PACKAGE_ENABLED（保留新dist）
```

### 6.2 生产回滚命令（Step 15失败时）

```bash
# 紧急回滚（<2分钟）
ssh -i ~/.ssh/aliyun_awkn root@8.148.245.29
cd /opt/awkn-life/awkn-life-backend/apps/api-server

# 1. 停止PM2
pm2 stop awkn-life-backend

# 2. 回滚dist
rm -rf dist
mv dist.old dist

# 3. 删除灰度配置
sed -i '/EVIDENCE_PACKAGE_ENABLED/d' .env.prod

# 4. 启动PM2
pm2 start awkn-life-backend

# 5. 验证
sleep 10
curl http://localhost:30000/api/v1/health
pm2 describe awkn-life-backend | grep -E 'status|unstable'
```

### 6.3 完整回滚（恢复到6月26日版本）

```bash
# 恢复整个/opt/awkn-life
ssh -i ~/.ssh/aliyun_awkn root@8.148.245.29
pm2 stop awkn-life-backend
rm -rf /opt/awkn-life
cp -r /opt/awkn-life-backup-YYYYMMDD_HHMMSS /opt/awkn-life
```
