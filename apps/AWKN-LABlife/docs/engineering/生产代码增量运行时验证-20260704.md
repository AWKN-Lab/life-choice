## 6. 问题分级

### P0（阻断）: 无
### P1（高风险）: 无

### P3（低风险）

**P3-1: `routeType` 字段在历史日志中未填充**
- 现象: `byRouteType` 全部归类为 `unknown`
- 根因: `llm-cost-dashboard.service.ts` 从 `llm-calls-*.log` 解析日志，但历史日志记录的 `routeType` 字段缺失或为空
- 影响: 看板无法按路由类型聚合成本（不影响总体成本统计）
- 修复建议: 在 LLM Gateway 调用入口统一记录 `routeType` 字段
