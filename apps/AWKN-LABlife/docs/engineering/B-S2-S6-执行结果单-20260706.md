## 三、关键发现：B-S2 遗漏与补丁

### 3.1 问题

B-S2 设计时只考虑了 service 层 `getTidePackage` 返回 tideJudgment，未考虑 controller 层免费用户分支（gated='partial'）会重新构造返回对象，**丢掉了 tideJudgment 字段**。

### 3.2 根因

`kline-tide.controller.ts` 第 105-138 行：

```typescript
if (!access) {
  const fullPkg = await this.ktService.getTidePackage(userId, options);
  const previewBars = fullPkg.klineBars.slice(0, 3);
  const previewSnapshots = fullPkg.stateSnapshots.slice(0, 3);
  const previewPhasePoints = fullPkg.phasePoints.slice(0, 3);
  return {
    klineBars: previewBars,
    stateSnapshots: previewSnapshots,
    phasePoints: previewPhasePoints,
    // ❌ 缺少 tideJudgment 字段
    meta: { ...fullPkg.meta, totalBars: ..., totalSnapshots: ..., totalPhasePoints: ... },
    gated: 'partial',
    ...
  };
}
```

### 3.3 补丁

```typescript
return {
  klineBars: previewBars,
  stateSnapshots: previewSnapshots,
  phasePoints: previewPhasePoints,
  // B-S2 (2026-07-05): 透传 tideJudgment（基于最新 snapshot 生成，与 preview 截取无关）
  tideJudgment: fullPkg.tideJudgment,
  meta: { ... },
  gated: 'partial',
  ...
};
```

### 3.4 设计合理性

tideJudgment 基于"最新 snapshot"生成，与 preview 截取（前3个）无关。免费用户看到的是前3个旧节点，但 tideJudgment 反映的是最新状态 — 这反而是合理的，因为状态判断应该是"当下"的，而非"3个月前"的。
