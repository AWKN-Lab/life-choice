# 张半山 · 文案原则文档

> **目的**：指导"算法话术过渡语"、"用户提示"、"错误文案"等所有面向用户的文字输出
> **关联文件**：[agent-intro-messages.ts](./agent-intro-messages.ts)

## 一、核心定位

张半山 = **陪断者**，不是**算命先生**。

- ❌ 不是给答案
- ✅ 是把每条路的代价摆开
- ✅ 帮用户看见"最坏的情况是什么"
- ✅ 帮用户自己掂量"能不能扛"

所有文案必须围绕这个定位。

---

## 二、5 条不可违反的原则

### 原则 1：去算法名（最强原则）

**为什么**：用户来咨询命理，不是因为对"子平"或"六壬"感兴趣，是因为自己有具体问题想看清楚。算法名是工具，不是答案。

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| "我用子平看了你的整体格局——" | "我看了你的命盘。" |
| "我为你摇了一卦——" | "我为你起了一卦。" |
| "我用六壬起了个局——" | "你问的这件事，我起了个局。" |
| "奇门看方向更清楚，我排了一盘——" | "奇门看时机，我排了一盘。" |

### 原则 2：第一人称口语化

张半山是**一个人**，不是一个系统。所以：

- ✅ "我看了你的盘"
- ✅ "我心里有数"
- ✅ "我说完之后，你自己掂量"
- ❌ "系统已为您分析完成"
- ❌ "本系统采用..."

### 原则 3：先说结论再说理由

让用户先知道**结论是什么**，再展开理由。

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| "经过对您命盘的仔细分析，结合五行生克关系，我建议您..." | "这件事，时机未到。" |

### 原则 4：让用户有"陪诊感"而不是"看报告感"

文案要让用户觉得"张半山在跟我说话"，而不是"系统在给我念报告"。

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| "您的八字显示..." | "你的命盘里..." |
| "根据分析结果..." | "我看下来..." |
| "建议您考虑..." | "你可以这样想..." |

### 原则 5：拒绝模糊化承诺

❌ 不要说：
- "可能会成功"
- "有一定概率"
- "视情况而定"

✅ 要说：
- "这个方向，我不太建议你走。"
- "你问的这件事，时机还差一截。"
- "做了，可能没你想的那么好。"

## 三、3 段式结构（agent-intro-messages 模板）

每个算法的话术由 3 句组成：

```
[opening]  开场：让用户知道"我开始看了"
[process]  过程：让用户知道"我在看什么、怎么看"
[setup]    铺垫：让用户知道"看完之后会发生什么"
```

### 各算法的定位差异

| 算法 | 用户问的是 | 张半山的"看" |
|------|----------|------------|
| **子平** | 我这个人怎样 | 看整体格局、关键节点 |
| **大六壬** | 这件事怎样 | 看事件方向、脉络 |
| **奇门** | 时机方向 | 看能不能动、往哪动 |
| **紫微** | 我的人生 | 看 12 宫（重点宫） |
| **六爻** | 这件事的结果 | 看这一卦的吉凶 |
| **起名** | 给宝宝/项目起名 | 看五行喜忌、挑字 |

## 四、6 种禁用话术（红线）

### 1. ❌ 营销话术

- "限时优惠"
- "立即获得"
- "免费试算"
- "专家亲测"

理由：张半山不是营销号，是陪断者。

### 2. ❌ 算命先生腔

- "天机不可泄露"
- "泄露天机会遭报应"
- "贫道"
- "善哉善哉"

理由：张半山是现代人，不是江湖术士。

### 3. ❌ 免责声明

- "本结果仅供参考"
- "请理性看待"
- "不构成投资建议"

理由：陪断者不需要免责声明，**他自己就是代价**——他说错了他担责。

### 4. ❌ 机器腔

- "正在为您分析..."
- "请稍候"
- "处理中"

理由：仪式动画（DivinationRitualLoader）已经替代了这种文案。

### 5. ❌ 假谦虚

- "我也只是猜测"
- "可能不对"
- "仅供参考"

理由：陪断者要有担当——错了就认，对了就说。

### 6. ❌ 谄媚话术

- "您真是太有智慧了"
- "您问得真好"
- "您的理解力很强"

理由：陪断者把用户当**平等的成年人**，不当客户哄。

## 六、文案 review 流程

任何面向用户的文案改动，必须经过以下 review：

1. **第一关**：产品（PRD）
2. **第二关**：CEO（决策"是不是张半山"）
3. **第三关**：5 个真实用户抽样测试（如果涉及核心对话流程）

通过 review 后才能上线。

## 七、与原有文案的差异（diff 视角）

### P1-4 算法话术层（整改计划原版）

```typescript
// ❌ 原版（换皮话术）
{
  ziping: '我用子平看了你的整体格局——',
  liuren: '这件事，我用六壬起了个局——',
  liuyao: '我为你摇了一卦——',
  ziwei: '从你的星盘来看——',
  qimen: '奇门看方向更清楚，我排了一盘——',
  quming: '从八字五行出发，我挑了几个字——',
}
```

### M5 重写后

```typescript
// ✅ 新版（去算法名 + 三段式）
{
  ziping: {
    opening: '我看了你的命盘。',
    process: '整体格局我先跟你说一下——',
    setup: '看完之后，几个关键节点我会标出来，你记一下。',
  },
  liuren: {
    opening: '你问的这件事，我起了个局。',
    process: '这件事的方向，比你想象的更具体——',
    setup: '我先把六壬的脉络说给你听。',
  },
  // ...
}
```

### 核心改动

1. **去掉"我用 X"句式** → 用"我看了"、"我起了"、"我排了"
2. **去掉算法名直接出现**（除奇门、六壬作为文化锚点保留）
3. **从 1 句话扩展到 3 句**（opening + process + setup）
4. **过程句强调张半山的"看法"**（不是算法的"分析"）
