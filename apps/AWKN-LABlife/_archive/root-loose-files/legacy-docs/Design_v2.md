# 人生决策宗师 - 设计文档 V2

## 设计概述
基于参考图片的精致东方命理风格，采用深邃星空背景配合金色点缀，营造神秘、高级、可信的视觉体验。

## 色彩系统

### 主色调
- **背景黑**: #0a0a0a (主背景)
- **深黑**: #000000 (纯黑区域)
- **卡片黑**: #141414 (卡片背景)
- **金色**: #c9a962 (主金色)
- **金色亮**: #e8d5a3 (高亮金色)
- **金色暗**: #8b7355 (暗金色)

### 辅助色
- **文字白**: #ffffff (主文字)
- **文字灰**: #999999 (次要文字)
- **文字暗**: #666666 (辅助文字)
- **边框色**: rgba(201, 169, 98, 0.2) (金色边框)
- **分割线**: rgba(255, 255, 255, 0.1)

## 视觉元素

### 背景
- 深邃星空背景图，带有星盘/罗盘元素
- 微妙的金色粒子漂浮效果
- 渐变光晕装饰

### 卡片
- 圆角: 16px
- 背景: rgba(20, 20, 20, 0.8)
- 边框: 1px solid rgba(201, 169, 98, 0.15)
- 阴影: 0 4px 24px rgba(0, 0, 0, 0.4)

### 按钮
- 主按钮: 金色渐变背景，圆角12px
- 次按钮: 透明背景+金色边框
- 悬浮: 金色光晕效果

### 图标
- 线性图标，金色描边
- 配合神秘符号（铃铛、剑、书等）

## 页面结构

### 首页
1. **顶部栏**: Logo + "我的咨询"按钮
2. **Hero区**: 
   - 主标题: "先把问题想清楚，再让答案有方向"
   - 副标题: "基于大六壬智慧 · 真太阳时校准 · 真人对话解读"
   - 主CTA: "立即提出我的问题"
   - 信任标签: "隐私严格保密 · 对话免费看"
3. **你将获得**: 三个功能卡片
4. **问事信息表单**: 地点、时间、称呼
5. **底部导航**: 首页、提出问题、宗师对话、我的

### 结果页
1. **顶部**: 铃铛图标 + "看事结果"
2. **问题展示**: 用户输入的问题
3. **分析结果卡片**:
   - 竞争决策/气运判定/未来走向
   - 带图标和详细说明
4. **查看推演依据**: 可展开
5. **VIP服务卡片**: 破局锦囊、醒神早帖

### 会员中心
1. **标题**: "把一次判断，变成持续陪伴"
2. **套餐卡片**: 轻会员月卡、单次深推
3. **权益对比表**

## 动画效果

### 入场动画
- 元素淡入 + 上移
- 卡片依次出现，间隔0.1s
- 金色粒子缓慢漂浮

### 交互动画
- 按钮悬浮: 金色光晕扩散
- 卡片悬浮: 轻微上浮 + 边框高亮
- 页面切换: 淡入淡出

### 持续动画
- 背景粒子漂浮
- 金色光晕呼吸效果
