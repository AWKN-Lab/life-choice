# 六壬神煞总览

本文件为六壬课局常用神煞的分类、起例、吉凶属性、适用占类及现代解读。供标注课传神煞、分析吉凶时引用。

---

## 神煞使用原则

1. **层次分明**：神煞分岁煞（年）、月煞、旬煞、干煞、支煞，各有权重，岁煞力量最大，月煞次之，旬煞又次之。
2. **以占类取舍**：不同占类使用不同神煞，如占官重天吏、皇书，占病重病符、死气，不可混用。
3. **吉凶互化**：神煞吉凶需结合课传生克判断，吉煞受克则吉减，凶煞受制则凶消。
