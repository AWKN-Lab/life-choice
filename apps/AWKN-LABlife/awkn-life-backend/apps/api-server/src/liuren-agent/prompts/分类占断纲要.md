# 《大六壬指南》分类占断纲要

本文件根据《大六壬指南》卷三、卷四提炼，事件类型、颗粒度、问事类别均使用简短编码。
保留核心类神、判断要点及常用口诀，可直接用于 Phase2 分析。

## 使用说明

1. **事件类型、颗粒度、问事类别**在智能体 Prompt 中直接引用编码即可
2. Phase2 分析时，系统通过映射表自动解析回原始含义
3. 保留核心类神、判断要点、常用口诀，保证分析逻辑完整
4. 这种简码方式可节省提示词字符量约 50%-60%，同时不影响功能
