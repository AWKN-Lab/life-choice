## 使用注意事项

1. 节气交接时刻需精确判断，中气前后的月将不同
2. 问事时间在中气当日，需确认是否已过交接时刻
3. 配合真太阳时校正使用，以当地真太阳时为准
4. 月将不可凭农历月份粗略估算
