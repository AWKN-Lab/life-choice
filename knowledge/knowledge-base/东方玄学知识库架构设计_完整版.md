# 东方玄学知识库 - 数据库架构设计（完整版）

**版本**: v3.0
**更新**: 2026-06-05
**颗粒度**: 字段级

---

## 一、核心问题诊断

### 当前问题
1. **神煞表颗粒度不够** - 缺少分类、起例规则、适用占类、现代解读
2. **八字基础数据缺失** - 十二长生、地支藏干、五虎遁、五鼠遁规则未结构化
3. **六壬规则不完整** - 九宗门、月将、贵人起例等未单独建表
4. **案例字段不完整** - 缺少详细的断语验证、案例分析链路

CREATE TABLE tian_gan (
