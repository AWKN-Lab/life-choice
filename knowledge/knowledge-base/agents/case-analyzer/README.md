# 命例判案专家 - 使用说明

> **版本**: v1.0  
> **创建时间**: 2026-06-05  
> **适用场景**: 命理判断验证、相似命例对比、理论实证

---

## 🎯 什么是命例判案专家？

命例判案专家是一个**以案例为核心的命理分析子智能体**。它的核心价值在于：

- 🔍 **检索相似命例** - 根据八字特征找到数据库中的相似案例
- 📊 **对比分析** - 对比格局、用神、人生轨迹的异同
- ✅ **理论验证** - 用实际命例验证命理判断的准确性
- 📈 **规律发现** - 从大量案例中统计发现命理规律

**核心理念**: 命理不是背诵典籍，而是用案例验证。

---

## 🚀 快速开始

### 方式 1：触发关键词（自动）

在对话中使用以下关键词，自动触发命例判案专家：

```
"帮我判案这个八字..."
"验证一下这个判断..."
"找相似命例..."
"对比一下..."
"这个八字如何分析..."
```

### 方式 2：直接调用（手动）

```python
from scripts.case_analyzer import CaseAnalyzer

# 创建判案专家
analyzer = CaseAnalyzer()

# 提交判案请求
report = analyzer.analyze(
    bazi={
        'year': '辛未',
        'month': '甲午', 
        'day': '甲寅',
        'hour': '丁卯'
    },
    user_judgment="木火通明格，身弱用火"
)

# 查看报告
print(report)
```

## 🔧 核心脚本使用

### case_analyzer.py

**功能**: 命例判案核心脚本

**用法**:
```bash
# 命令行方式
python scripts/case_analyzer.py --bazi "辛未 甲午 甲寅 丁卯" --judgment "木火通明格"

# 交互式
python scripts/case_analyzer.py --interactive
```

**参数**:
- `--bazi`: 八字四柱，格式"年柱 月柱 日柱 时柱"
- `--judgment`: 用户的格局/用神判断（可选）
- `--top-k`: 返回相似命例数量，默认5
- `--output`: 输出报告路径

## ⚠️ 使用限制

1. **数据覆盖有限** - 目前160条命例，某些日干/格局可能无案例
2. **仅供参考** - 判案结果供参考，不构成绝对判断
3. **需要验证** - 命理判断需结合实际情况综合考量
