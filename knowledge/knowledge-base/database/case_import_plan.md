## 🔧 技术方案

### 1. 命例识别模式

```python
# 八字格式模式
PATTERNS = [
    # 乾造/坤造格式
    r'[乾坤]造[：:]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])年\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])月\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])日\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])时',
    
    # 命造格式
    r'命造[：:]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])\s+([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])\s+([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])\s+([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])',
    
    # 四柱格式
    r'四柱[：:]\s*年柱\s*[:=]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥]).*?月柱\s*[:=]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥]).*?日柱\s*[:=]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥]).*?时柱\s*[:=]\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])',
    
    # 纯八字格式（年月日时）
    r'([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])年\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])月\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])日\s*([甲乙丙丁戊己庚辛壬癸][子丑寅卯辰巳午未申酉戌亥])时',
]
```

### 2. 字段提取规则

| 字段 | 提取规则 | 示例 |
|------|---------|------|
| 年柱 | 年柱/年/岁次后的干支 | 甲子 |
| 月柱 | 月柱/月后的干支 | 丙寅 |
| 日柱 | 日柱/日/日元后的干支 | 丁卯 |
| 时柱 | 时柱/时后的干支 | 戊申 |
| 日干 | 日柱天干 | 丁 |
| 性别 | 乾造=男，坤造=女 | 男 |
| 格局 | 原文"X格"、"入X格" | 正官格 |
| 用神 | 原文"用X"、"喜X" | 金水 |
| 来源 | 典籍名称 | 三命通会 |
