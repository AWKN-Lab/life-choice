- **正印格**：月令正印透干，身弱喜之

- **正财格**：月令正财透干，身强能任
- **偏财格**：月令偏财透干，慷慨好施
- **食神格**：月令食神透干，福寿双全
- **伤官格**：月令伤官透干，聪明傲物

#### 1.4 化气格

### 三、病药法则（Disease & Medicine Laws）

#### 3.1 病药说核心
> 《神峰通考》："有病方为贵，无伤不是奇；格中如去病，财禄两相随。"

#### 3.2 病之类型
- **太过之病**：五行过旺，需克制
- **不及之病**：五行过弱，需生扶
- **偏枯之病**：五行偏颇，需调和
- **交战之病**：两神相战，需通关

#### 3.3 药之取用
- **克抑之药**：太过者，克之抑之
- **生扶之药**：不及者，生之扶之
- **调和之药**：偏枯者，调之和之
- **通关之药**：交战者，通之关之

#### 3.4 病药实例
- **金多水浊**：土重金埋，水弱难流 → 用木疏土
- **木多火塞**：木盛火熄，光明不显 → 用金制木
- **水多木漂**：水泛木浮，根基不稳 → 用土制水
- **火多土焦**：火炎土燥，生机断绝 → 用水润土

### 四、通关法则（Mediation Laws）

#### 4.1 通关原理
> 两神相战，取其中和之神以通之

#### 4.2 常见通关组合
- **金木交战**：用水通关（金生水，水生木）
- **木土交战**：用火通关（木生火，火生土）
- **土水交战**：用金通关（土生金，金生水）
- **水火交战**：用木通关（水生木，木生火）
- **火金交战**：用土通关（火生土，土生金）

#### 4.3 通关应用
- **官伤相战**：用财通关（伤生财，财生官）
- **印财相战**：用官通关（财生官，官生印）
- **食枭相战**：用比劫通关（食生比，比生枭）

## 🔍 使用方式

### 方式 1：按图索骥
根据具体命局特征，查找对应法则。

**示例**：
```
命局：甲木生于子月，满盘金水
→ 查找"从格法则" → 从杀格/从旺格
→ 查找"调候法则" → 冬木需火
→ 查找"病药法则" → 寒木向阳，丙火为急
```

### 方式 2：智能体调用
通过关键词检索，快速定位法则。

**示例查询**：
- "什么是从财格？" → 返回从格法则 1.3
- "冬天出生的甲木需要什么？" → 返回调候法则 2.3
- "金木交战怎么办？" → 返回通关法则 4.2
- "伤官见官如何化解？" → 返回通关法则 4.3

### 方式 3：案例分析
结合实际命例，应用对应法则。
