### 2. 查询接口

**功能**:
- 语义搜索（支持中文）
- Top-K 检索
- 相关度排序
- 元数据过滤

**使用示例**:
```python
from query_interface import ZipingKnowledgeDB

db = ZipingKnowledgeDB()
results = db.search("甲木日主什么时候用火？", top_k=5)

for r in results:
    print(f"[{r['category']}] {r['text']}")
    print(f"相关度：{1-r['distance']:.2%}\n")
```
