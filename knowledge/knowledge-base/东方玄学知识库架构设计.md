# 东方玄学知识库 - 数据库架构设计

## 一、设计理念

### 核心理念
- **统一知识图谱**：八字、六爻、六壬、紫微斗数等共享基础五行、干支、神煞数据
- **案例驱动**：每个案例包含完整"出生信息→排盘→分析→断语→验证"链条
- **可扩展性**：新增术数类型只需扩展表结构，不破坏现有数据

### 数据分层
```
┌─────────────────────────────────────────┐
│           知识层（Reference）              │
│   干支、五行、神煞、星曜、宫位、卦象       │
├─────────────────────────────────────────┤
│           规则层（Rules）                │
│   起盘规则、断语规则、格局判定规则         │
├─────────────────────────────────────────┤
│           案例层（Cases）                │
│   命例、卦例、盘例（带分析结果）           │
├─────────────────────────────────────────┤
│           对话层（Consultations）        │
│   咨询记录、AI对话、分析报告              │
└─────────────────────────────────────────┘
```

### 2.2 八字命理表（子平术）

```sql
-- 八字命例主表
CREATE TABLE bazi_cases (
    id INTEGER PRIMARY KEY,
    case_no TEXT NOT NULL UNIQUE,   -- 案号：BZ-2024-0001
    name TEXT,                        -- 姓名（可匿名）
    gender TEXT,                      -- 男/女

    -- 出生时间
    birth_year INTEGER NOT NULL,
    birth_month INTEGER NOT NULL,
    birth_day INTEGER NOT NULL,
    birth_hour INTEGER,              -- 0-23
    birth_minute INTEGER,
    lunar_calendar BOOLEAN DEFAULT 1, -- 是否农历
    leap_month BOOLEAN DEFAULT 0,    -- 是否闰月
    birth_location TEXT,              -- 出生地（用于真太阳时）

    -- 排盘结果
    year_zhu TEXT NOT NULL,           -- 年柱
    month_zhu TEXT NOT NULL,           -- 月柱
    day_zhu TEXT NOT NULL,            -- 日柱
    hour_zhu TEXT,                    -- 时柱
    day_master TEXT NOT NULL,          -- 日主（天干）
    day_master_strength TEXT,          -- 日主强弱

    -- 大运信息
    yun_start_age INTEGER,            -- 起运年龄
    yun_direction TEXT,              -- 顺运/逆运
    da_yun_list TEXT,                -- JSON：大运列表

    -- 元信息
    source TEXT,                      -- 数据来源
    notes TEXT,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    verified BOOLEAN DEFAULT 0
);

-- 八字格局表
CREATE TABLE bazi_patterns (
    id INTEGER PRIMARY KEY,
    case_id INTEGER REFERENCES bazi_cases(id),
    pattern_name TEXT NOT NULL,       -- 格局名称：正官格、七杀格...
    pattern_type TEXT,               -- 格局类型：正格、外格
    condition TEXT,                   -- 成格条件
    characteristics TEXT,             -- 格局特点
    evaluation TEXT,                 -- 格局评价
    notes TEXT
);

-- 用神表
CREATE TABLE bazi_yong_shen (
    id INTEGER PRIMARY KEY,
    case_id INTEGER REFERENCES bazi_cases(id),
    yong_shen_type TEXT NOT NULL,    -- 用神、喜神、忌神、仇神
    gan_zhi TEXT NOT NULL,            -- 具体干支
    reason TEXT,                     -- 选取理由
    evaluation TEXT,                  -- 旺衰判断
    notes TEXT
);

-- 大运表
CREATE TABLE bazi_dayun (
    id INTEGER PRIMARY KEY,
    case_id INTEGER REFERENCES bazi_cases(id),
    start_age INTEGER NOT NULL,       -- 开始年龄
    end_age INTEGER NOT NULL,        -- 结束年龄
    start_year TEXT,                  -- 起运干支
    zhu TEXT NOT NULL,               -- 运柱
    gan_tian_tong TEXT,              -- 天干通气
    zhi_chong TEXT,                  -- 地支冲合
    description TEXT
);

-- 流年表
CREATE TABLE bazi_liu_nian (
    id INTEGER PRIMARY KEY,
    case_id INTEGER REFERENCES bazi_cases(id),
    dayun_id INTEGER REFERENCES bazi_dayun(id),
    year INTEGER NOT NULL,           -- 年份
    gan_zhi TEXT NOT NULL,           -- 流年干支
    tian_gan_wu_xing TEXT,           -- 流年天干五行
    di_zhi_wu_xing TEXT,             -- 流年地支五行
    wu_xing_impact TEXT,             -- 五行生克
    liu_nian_summary TEXT,           -- 流年总断
    key_events TEXT,                 -- 关键事件
    notes TEXT
);

-- 人生事件表
CREATE TABLE bazi_life_events (
    id INTEGER PRIMARY KEY,
    case_id INTEGER REFERENCES bazi_cases(id),
    event_type TEXT NOT NULL,        -- 婚姻、事业、财运、健康...
    event_year INTEGER,              -- 事件年份
    event_age INTEGER,               -- 发生年龄
    event_description TEXT,          -- 事件描述
    evaluation TEXT,                 -- 事件评价
    verification TEXT,               -- 验证情况
    notes TEXT
);

-- 八字断语表（知识库）
CREATE TABLE bazi_judgments (
    id INTEGER PRIMARY KEY,
    pattern_type TEXT NOT NULL,     -- 格局类型
    condition TEXT NOT NULL,         -- 条件组合
    judgment TEXT NOT NULL,         -- 断语
    example_case_id INTEGER,         -- 示例案例
    confidence INTEGER DEFAULT 3,   -- 置信度 1-5
    source TEXT,                     -- 出处
    notes TEXT
);
```

## 六、命名规范

- 表名：`系统类型_模块`（如 bazi_cases、yao_reference）
- 案号：`系统-年份-序号`（如 BZ-2024-0001）
- 字段：snake_case 中文注释
- 时间：ISO 8601 格式
