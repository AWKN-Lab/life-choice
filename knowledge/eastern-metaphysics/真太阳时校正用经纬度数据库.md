# 真太阳时校正用经纬度数据库

本文件为"新六壬毕法宗师"智能体的知识库之一，包含中国主要城市的经纬度数据，用于真太阳时计算。六壬起课必须使用真太阳时，而非北京时间。

---

## 一、真太阳时计算原理

### 公式
```
真太阳时 = 北京时间 + (当地经度 - 120°) × 4分钟/度
```

### 说明
- 北京时间以东经120°为基准
- 每偏离1度，时间偏差4分钟
- 东经>120°的地方，真太阳时比北京时间早
- 东经<120°的地方，真太阳时比北京时间晚

## 三、使用示例

### 示例：广州起课
```
北京时间：14:30
广州经度：113.3°E
真太阳时校正：-26.8分钟
真太阳时 = 14:30 - 26.8分钟 = 14:03:12
占时：未时（13:00-15:00）
```

### 示例：上海起课
```
北京时间：14:30
上海经度：121.5°E
真太阳时校正：+6分钟
真太阳时 = 14:30 + 6分钟 = 14:36
占时：未时（13:00-15:00）
```

---

## 四、注意事项

1. **精确到分钟**：真太阳时计算需精确到分钟
2. **时辰交接**：时辰交接时刻（如13:00）需特别注意
3. **夏令时**：中国1992年后不再实行夏令时
4. **偏远地区**：偏远城市需自行查经纬度
