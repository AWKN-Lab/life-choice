# 六壬起课基础规则库

本文件为"新六壬毕法宗师"智能体的知识库之一，包含六壬起课的核心规则和基础流程。六壬起课是整个预测体系的起点，规则的准确性直接影响课局质量。

---

## 一、起课核心原则

### 1. 中气换将
- **核心规则**：月将更换以中气为界，每个中气过后更换为下一月将
- **参考**：详见《节气月将对照表.md》
- **注意**：节气交接时刻需精确到分钟，不可粗略估算

### 2. 正时起课
- **核心规则**：以问事当下的真太阳时为准
- **真太阳时计算**：北京时间 + 经度校正
- **参考**：详见《真太阳时校正用经纬度数据库.md》

### 3. 地盘固定
- **核心规则**：地盘十二支固定不动，顺时针排列
- **顺序**：子→丑→寅→卯→辰→巳→午→未→申→酉→戌→亥
- **方位**：子在北，午在南，卯在东，酉在西

## 二、起课标准流程

### Step 1: 确定月将
```
1. 查询问事日期所在节气区间
2. 以中气为界确定月将
3. 记录月将名称和地支
```

### Step 2: 确定占时
```
1. 获取问事当下的北京时间
2. 根据所在地经度计算真太阳时
3. 确定占时地支
```

### Step 3: 安天盘
```
1. 将月将加于占时之上
2. 顺时针排列十二天将
3. 形成天地盘叠加格局
```

### Step 4: 起四课
```
1. 以日干起第一课（日干上神为第一课上）
2. 以第一课上神起第二课（上神上神为第二课上）
3. 以日支起第三课（日支上神为第三课上）
4. 以第三课上神起第四课（上神上神为第四课上）
```

### Step 5: 发三传
```
1. 根据九宗门规则发三传
2. 确定初传、中传、末传
3. 标注三传所属（初中末）
```

### Step 6: 配天将
```
1. 根据贵人起例确定贵人位置
2. 顺逆排列十二天将
3. 配于三传四课之上
```

## 四、贵人起例

### 昼贵人与夜贵人
- **昼贵人**：丑（牛）至未（羊）时用昼贵
- **夜贵人**：申（猴）至子（鼠）时用夜贵

### 贵人顺逆
- **顺行**：贵人临亥至辰，顺行排列
- **逆行**：贵人临巳至戌，逆行排列
