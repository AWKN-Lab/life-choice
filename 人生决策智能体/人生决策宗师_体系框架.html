定位宣言：为什么我们不是另一个算命 App

SECTION 03

六大独创引擎

这六个引擎是天福 Agent 及所有同类产品不具备的。它们不是"更好的排盘"，而是全新的分析范式和决策工具。

📈

人生 K 线引擎

Life K-Line Engine

将金融 K 线的 OHLCV 隐喻应用于人生轨迹量化。每条蜡烛代表一个月的综合状态： 开盘=月初潜力、最高=机会天花板、最低=风险底线、 收盘=综合落点、成交量=事件激活度。 七条人生线（事业/财富/健康/关系/成长/自由/缓冲）叠加在 K 线之上，形成"命运走势 + 维度拆解"双层视图。

技术实现：ECharts 蜡烛图 + 七维度折线 · 数据源：calcEngine 月度聚合
🌊

潮汐相位引擎

Tide & Phase Space Engine

借用物理学相空间概念，用承载力（Capacity）× 无序度（Entropy）两个核心指标构建四象限： 稳健扩张（绿）、高压探索（橙）、收敛修复（蓝）、风险暴露（红）。 12 维状态雷达展示你在能量/恢复/情绪/清晰/流动/动力/支撑/能动/秩序/成长/选择权/缓冲 十二个维度的当前值 vs 历史基准线。

技术实现：ECharts 雷达图 + 散点图 · 12维 StateSnapshot · 四象限分类器
🏛️

枢密院结构化思维引擎

Shumiyuan Structured Thinking

不是 AI 直接给答案，而是引导你自己想清楚。四步法：
① 说——倾诉问题
② 摆——AI 拆成可编辑卡片，你补充细节
③ 见——AI 揭示核心卡点 + 风险 + 三种走法 + 最小一步
④ 派——根据结论智能路由到下一步行动

技术实现：Speak→Spread→Bottom→Dispatch 四阶段 API · 可编辑卡片组件
⚖️

选择损益矩阵

Choice Gain/Loss Matrix

不预测唯一结果，而是模拟每条路的得与失。横轴是可选路径（乐观/中性/悲观），纵轴是影响维度（事业/财富/关系/健康...）。 每个格子标注"走这条路，在这个维度上你会得到什么、失去什么"。帮助用户从"我该选哪条路"变成"每条路的代价我能不能承受"。

技术实现：ChoiceSimulationEngine · 多维度损益计算 · 交互式矩阵组件
🧬

决策孪生体

Personal Decision Twin

持续学习的个人决策模式模型。通过事件账本记录你的每一次决策，通过反馈修正校准你的行为基线， 最终形成一个数字化的"你"——不是命盘上理论的你，而是真实行为模式中的你。 后续每次分析都自动关联这个孪生体的完整上下文，让建议越来越贴合你的实际情况。

技术实现：PersonalPatternModel · PolicyEngine · CorrectionEngine · 8层内核架构
🔗

证据置信图谱

Evidence Confidence Graph

每条结论都可追溯到四层证据：算法层（精确计算）→ 古籍层（经典原文引用）→ 统计层（置换检验 / Bootstrap 置信区间）→ LLM 层（语义综合）。 置信度以百分比标注，用户可以点击查看每层证据的具体来源。不是"AI 说的"，而是"哪本书的第几卷、多少次统计验证支撑的"。

技术实现：EvidenceNode + EvidenceEdge 图结构 · ChromaDB 向量检索 · 置信度评分器

SECTION 05

信任体系：四层证据链

天福展示推理步骤——"从排盘到取象到校验"。我们更进一步：每一步推理不仅可见，还标注证据来源和置信度。四层证据层层递进，构成可审计的信任体系。

算法层
精确计算，零误差。天干地支、五行分布、十神、纳音、长生、空亡——全部由确定性算法产出，不经过 LLM。排盘结果 100% 可复现、可审计。大六壬的四课三传、奇门的九宫八门同样由规则引擎精确计算。
古籍层
每条推论引用经典原文。知识库覆盖 21 部命理经典（子平真诠、滴天髓、穷通宝鉴、大六壬大全、奇门遁甲秘笈...），通过 RAG 向量检索精准匹配。不是"AI 觉得"，而是"《子平真诠》卷三第十七节说"。
统计层
置换检验 + Bootstrap 置信区间。命理编码不等于命理验证。我们通过严格的统计方法验证每个命理信号的稳定性：滚动原点评估、消融实验、Diebold-Mariano 检验。每个信号的预测力都有量化的置信区间。
LLM 层
语义综合，而非臆造。LLM 只做一件事：把前三层的结构化结论翻译成自然语言。反幻觉机制确保 LLM 不添加知识库中没有的信息。规则引擎兜底——如果 LLM 输出与规则冲突，自动降级为算法结果。

反幻觉三重保险

🛡️ 规则引擎兜底

核心推论由确定性规则引擎产出，LLM 生成结果必须与规则一致。如果冲突，自动降级为算法结果，确保核心判断永远不会"胡说"。

📚 知识库强制引用

RAG 检索强制要求 LLM 的每个推论都附带知识库出处。没有引用的结论会被标记为"推测性"，降低置信度显示。

📊 置信度可视化

每条结论都标注置信度百分比。用户可以展开查看四层证据的具体内容。高置信结论加粗显示，低置信结论灰色标注并附注"仅供参考"。
