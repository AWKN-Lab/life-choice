# 「人生决策宗师」全局体验升级 `.design` 原型计划

## 一、诊断：当前前端与内核的差距

| 内核能力 | 前端现状 | 差距等级 |
|---|---|---|
| 八层闭环内核（事件感知→模式发现） | 零传达，用户只看到"提问-回答" | P0 |
| 时位心三维框架（内核定义） | 降级为 3 个圆环仪表盘，丢失内核深度 | P1 |
| 终局形态"三联屏"（相位屏/试算屏/证据屏） | 完全不存在 | P0 |
| 反馈纠偏闭环（准/部分准/不准） | FeedbackWidget 仅在 ResultPage 出现，无存在感 | P1 |
| 命理低权重原则 | 首页"张半山·东方术数专家"占首屏核心位 | P0 |
| 系统会越来越准 | 零传达 | P1 |
| K 线页亮色模式 | 32 处硬编码 HEX 值，亮色完全不可用 | P0 |

---

## 二、升级策略总纲

### 设计理念：「决策操作系统，不是算命」

**一句话定位升级**：
- 当前：`命运没有标准答案，但博弈有最优解` + `张半山·东方术数专家`
- 升级为：`你的人生，值得一套操作系统` + `命运可编码、可跟踪、可追溯`

**三个叙事层级重排**：
1. **第一层（用户第一眼）**：这不是算命，是一个帮你做人生决策的系统
2. **第二层（用户探索时）**：公式、K线、雷达、相位空间——你的命运有坐标系
3. **第三层（用户深入后）**：东方术数是底层引擎之一，反馈驱动系统越来越准

### 信息架构重定义

**当前导航**：首页 | 咨询 | K线 | 历史 | 我的

**升级导航**：首页 | 潮汐 | K线 | 账本 | 我的

关键变化：
- "咨询"降级为首屏内入口，不再占底部导航
- "潮汐"升级为一级入口（当前被埋在 CoreAbilities 里）
- "历史"升级为"账本"概念（传达反馈闭环存在感）

---

## 三、视觉方向

### 设计语言：「精密仪器」而非「玄学神坛」

保留现有 token 体系，调整叙事语义：

| 元素 | 当前语义 | 升级语义 |
|---|---|---|
| 金色主色 | 命理/玄学/高贵 | 数据高亮/系统核心/重要信号 |
| 紫色辅色 | 神秘/灵性 | 多维分析/第二视角 |
| 青绿 tertiary | 风水/生机 | 安全信号/正向反馈 |
| 深蓝底色 | 神秘夜空 | 数据仪表盘/专注环境 |
| 玻璃拟态卡片 | 仙气/飘逸 | 信息层叠/数据面板 |

### 移动端优先
- 375px 基准宽度
- 关键信息首屏可见
- 触控热区 ≥ 44px
- 图表最小高度 280px

## 四、`.design` 画布页面清单（共 10 页）

### 页面 1：首页（暗色）

**传达目标**：用户第一眼感受到"这是我的人生操作系统"

区块顺序：
1. **HeroBanner**：标题「你的人生，值得一套操作系统」+ 副标题「命运可编码、可跟踪、可追溯」
2. **系统状态卡片**（登录后）：相位象限标签 + 时位心三组速览；未登录：「填写生辰，激活你的决策操作系统」
3. **CriticalMoments**（3 卡片）：职业判断 / 关系决策 / 时机选择——决策场景语言
4. **EngineFeatures**（6 卡片）：保留公式作为差异化锚点，强化"可编码、可开关、可回测"
5. **校准进度暗示**：「系统已为你分析 N 次，基于你的反馈持续校准中」
6. **引擎说明**（底部小卡片）：「底层引擎：东方术数 + 系统思维 + 算法验证」

### 页面 2：首页（亮色）
- 同页面 1 的亮色模式版本

### 页面 3：潮汐页（暗色）

**传达目标**：用户看到"我处于什么状态"——时位心三维框架正确呈现

结构：
1. **相位象限标签**（顶部）：四象限颜色编码 + 一句话行动指引
2. **Tab 1「相位总览」**：
   - 「时」面板：流动性 / 可选性 / 惯性（3 条维度条 + 基准线）
   - 「位」面板：支撑力 / 行动力 / 秩序 / 成长 / 缓冲（5 条维度条）
   - 「心」面板：能量 / 恢复力 / 情绪 / 清晰度（4 条维度条）
   - 统一判断摘要
3. **Tab 2「时间轴」**：因子线 + 时间窗 + 状态概率
4. **Tab 3「相位空间」**：四象限散点图

### 页面 4：潮汐页（亮色）
- 同页面 3 的亮色模式版本

### 页面 5：K 线页（暗色）

**传达目标**：命运有 K 线，趋势可看见

结构（分层折叠）：
1. **第一层（默认展开）**：K 线图表 + 趋势判断（一行文字）
2. **第二层（点击展开）**：时位心三组速览 + 维度切换按钮
3. **第三层（点击展开）**：操盘证据层 + 支撑压力转向

颜色全部使用 CSS token，无硬编码 HEX。

### 页面 6：K 线页（亮色）
- 同页面 5 的亮色模式版本

### 页面 7：账本页（暗色）

**传达目标**：系统有记忆，会越来越准

结构：
1. **系统置信度仪表**：总反馈数 / 准确率 / 校准次数
2. **事件时间线**：事件类型图标 + 时间 + 关键结论摘要
3. **反馈入口**：每条事件旁「这条判断准吗？」按钮
4. **底部文案**：「基于你的反馈，系统持续校准中」

### 页面 8：账本页（亮色）
- 同页面 7 的亮色模式版本

### 页面 9：BottomNav 导航组件
- 5 项：首页 / 潮汐 / K线 / 账本 / 我的
- 暗色 + 亮色双状态

### 页面 10：设计 Token 总览
- 颜色变量表 + 字体体系 + 间距/圆角/阴影规范
- K 线页颜色 token 映射表

## 七、假设与决策

1. **保留现有 token 体系**：不重新设计颜色，复用 AETHERIA token，只调整语义叙事
2. **不做咨询页原型**：咨询功能保留为对话式入口，不在此次原型范围内
3. **不做"我的"页原型**：用户设置页面不在此次升级核心范围
4. **账本页为概念原型**：事件数据结构依赖后端，原型展示 UI 形态即可
5. **ECharts 图表用静态截图**：`.design` 原型中 K 线图用静态截图或 CSS 模拟，不做交互式图表
