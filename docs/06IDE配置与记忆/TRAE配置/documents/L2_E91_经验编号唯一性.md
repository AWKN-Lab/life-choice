# E91｜经验编号必须全局唯一性校验

## 触发条件
经验编号 / E编号 / 复盘沉淀 / 编号冲突 / 经验写入

## 教训
复盘产出 E73-E77，但与 awkn-agent 项目已有 E73-E77 冲突。编号冲突导致经验索引混乱，同一编号指向不同经验。

## 反例
复盘时没有查 L2 目录已有编号，直接从 E73 开始编号。实际 L2 目录中 E73-E77 已有 6 个文件属于 awkn-agent 项目（harness auto-session / 增量部署 / 数据库位置 / SCP 脚本 / 代码交付 / 不膨胀原则）。

## 判断规则
复盘沉淀经验编号前必须：
1. Grep L1/L2 目录已有 E 编号，确认最大编号
2. 从最大编号+1 开始分配新编号
3. 编号格式：E{数字}，数字递增不重复
4. 跨项目共享编号空间（L1/L2 是全局的）
