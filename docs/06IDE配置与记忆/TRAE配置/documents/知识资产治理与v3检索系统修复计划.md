**怎么做**:
```python
# 新的 load_all() 逻辑
INDEX_FILE = os.path.join(_PROJECT_ROOT, 'knowledge', 'processed', 'classics_index.jsonl')
MANIFEST_FILE = os.path.join(_PROJECT_ROOT, 'knowledge', 'processed', '_manifest.json')

def load_all() -> Dict:
    items = []
    if os.path.exists(INDEX_FILE):
        with open(INDEX_FILE, encoding='utf-8') as f:
            for line in f:
                it = json.loads(line)
                items.append({
                    'source': it.get('source', ''),
                    'text': it.get('text', '')[:500],
                    'system_type': it.get('system_type', 'bazi'),
                    'book': it.get('book', ''),
                    'passage_id': it.get('passage_id', ''),
                })
    # 按 system_type 分组
    by_system = {}
    for it in items:
        sys = it['system_type']
        by_system.setdefault(sys, []).append(it)
    manifest = {}
    if os.path.exists(MANIFEST_FILE):
        manifest = json.load(open(MANIFEST_FILE, encoding='utf-8'))
    return {
        'items': items,
        'by_system': by_system,
        'sources': {'total': len(items), 'books': manifest.get('total_books', 0)},
        'manifest': manifest,
    }
```

**怎么做**:
```python
def search(route_type: str, query: str, tags: List[str], limit: int) -> List[KnowledgeItem]:
    sys_key = 'bazi' if route_type in ('ziping', 'bazi') else route_type
    # 从 by_system 取对应分类 + 通用 fallback（bazi/zhouyi/other）
    pool = DATA.get('by_system', {}).get(sys_key, [])
    results = []
    for item in pool:
        score = keyword_match(query, item['text'])
        for tag in tags:
            if tag.lower() in item['text'].lower():
                score += 0.3
        if score > 0.1:
            source_id = item.get('passage_id', item['source'])[:40]
            results.append(KnowledgeItem(
                sourceId=source_id,
                title=item.get('book', item['source'].split('/')[-1]),
                text=item['text'][:300],
                score=round(min(score, 0.99), 2)
            ))
    results.sort(key=lambda x: x.score, reverse=True)
    return results[:limit]
```

def split_md_content(content: str, book: str, source: str, system_type: str) -> List[Dict]:
    items = []

## 3. 假设与决策

### 3.1 假设

1. **假设**: 知识服务运行在 127.0.0.1:8701，后端 orchestrator 通过 HTTP 调用
   - **依据**: main.py L357 `uvicorn.run(app, host="127.0.0.1", port=8701)`
   - **风险**: 如果生产未启动知识服务，G1 修复后用户仍无法使用

2. **假设**: classics_index.jsonl 的 137337 条数据质量可接受（只是分类+切分问题）
   - **依据**: 审计报告确认结构完整、无损坏行、无重复 passage_id
   - **风险**: 如果内容质量差（HTML 噪声、乱码），G3 需要额外清洗

3. **假设**: 生产服务器有足够空间重新生成索引
   - **依据**: embeddings.npy 约 536MB，服务器磁盘 85% 已用（4.6GB 可用）
   - **风险**: 如果空间不足，需要在本地生成后上传

### 3.2 决策

1. **决策**: G1 优先于 G0（与 PRD 不同）
   - **理由**: `/retrieve` 返回 0 条是当前故障，用户正在受影响；G0 是预防性保护
   - **风险**: 如果 G1 修复过程中 .git 损坏，可能丢失未备份的悬空对象（概率低）

2. **决策**: 分类体系用 12 个（非 PRD 的 17 个）
   - **理由**: 17 个中 5 个可能无对应书籍（western_astrology/tarot/rune/reference/taiyi）
   - **列表**: bazi/ziwei/qimen/liuren/liuyao/meihua/zhouyi/fengshui/quming/xiangshu/daoism/other

3. **决策**: ID 体系先用 SHA256，UUIDv5 延后
   - **理由**: UUIDv5 + 6 种关系是完整图书情报学本体，工作量过大
   - **列表**: 先做 `source_id = SHA256(原始文件)` 去重，版本关系只做 `duplicate_binary`

4. **决策**: G6 设为有条件
   - **理由**: TF-IDF 对精确词面匹配（经典原文）反而更准，需先量化效果
   - **条件**: recall@10 < 0.7 或 precision@10 < 0.6 才做 G6

5. **决策**: 使用独立 worktree（沿用 PRD 约束第 7 条）
   - **理由**: 避免污染主仓库
   - **怎么做**: 在 `c:\Users\10919\Desktop\AWKN-Lab\人生决策宗师-knowledge-worktree` 创建独立 worktree
