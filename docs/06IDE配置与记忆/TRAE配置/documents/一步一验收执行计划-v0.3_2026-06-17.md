## A. 目标与边界

- **目标一句话**：修复前后端认证集成，让三个页面真正可用，同时补齐部署配置
- **本轮做**：
  1. M1 前后端认证集成修复（P0）
  2. M4 数据库配置统一（P1）
  3. M2 HTTPS Docker 模式（P1）
  4. M3 CI/CD 补部署阶段（P1）
  5. M5 前端样式修复（P2）
- **本轮不做**：
  1. 不做 Supabase/PostgreSQL 迁移
  2. 不做 E2E 自动化测试
  3. 不做 staging 环境
  4. 不做大规模重构
- **约束**：不修改后端 Controller 路由定义、不修改 Prisma schema 结构、不引入新依赖

## 下次遇到类似情况，先做哪 3 件事？

1. **先调研再下结论**：不要基于假设判断"未实现"，先读代码确认事实
2. **认证集成优先**：前后端认证不匹配是最高优先级，其他功能都依赖它
3. **一步一验证**：每改一个文件就 tsc + build，不要攒到最后一起验证
