# E89｜前端页面≠空壳，需读代码再判断

## 触发条件
空壳 / 空页面 / 页面无内容 / 页面不完整

## 教训
3 个页面被标记为"空壳"，实际都有完整 UI 逻辑（317/296/210 行）。问题不是页面空，而是后端 API 未实现。

## 反例
浏览器访问时只看到暗夜模式按钮就判断为"空壳"，没有读源码。实际 ShumiyuanPage 317 行、TongjianPage 296 行、XingtuPage 210 行，都有完整 UI 逻辑。

## 判断规则
判断页面是否为空壳前：
1. 先读源码确认行数和 UI 逻辑
2. 区分"页面空壳"和"后端 API 未实现"
3. 前端有 UI 但无数据 = 后端问题，不是前端问题
