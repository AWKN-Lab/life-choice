## 核心发现

### 发现 1：PowerShell 隐式输出是跨脚本复发的陷阱（→ E91）
- 部署脚本 `Invoke-BuildCommand` 的 exit code 误判根因是 PowerShell 函数会返回所有管道输出
- 3 次修复（cmd /c → Start-Process → Tee-Object → Out-Null + Write-Host）才定位到根因
- 修复模式：`| Out-Null` + `Write-Host` 显式输出

### 发现 2：组件写了 != 页面用了（→ E92）
- 8 个组件（conclusion 4 + home 3 + form 1）写完 >=30 天从未被任何页面引用
- 根因：开发流程缺少"组件→页面接入"的 checklist
- 修复模式：组件开发完成后 Grep 验证引用 + 路由接线 + 构建验证

### 发现 3：修复后跳过了再审核（→ E93）
- 审核发现 4 个问题 → 修复 → 直接进入 CI/CD，缺少审核视角的二次确认
- 虽然 CI/CD 全通过，但缺少"修复是否引入新问题"的审核门禁
- 修复模式：修复后至少跑一次快速审核（安全扫描 + diff 审查 + 测试覆盖）
