## 四、技术实现细节

### 4.1 UV 查询（Prisma distinct）

```typescript
// 总 UV（按 userId 去重，匿名用户按 sessionId 去重）
const totalUV = await this.prisma.pageVisit.groupBy({
  by: ['userId'],
  _count: { userId: true },
});
// 注意：userId 为 null 时按 sessionId 聚合
```

### 4.2 漏斗查询

```typescript
const funnelData = await this.prisma.userActivity.groupBy({
  by: ['activityType'],
  _count: { id: true },           // PV
  _count: { userId: true },       // ⚠️ Prisma 不支持 distinct count in groupBy
});
// 需要原始查询：
// SELECT activity_type, COUNT(*) as pv, COUNT(DISTINCT user_id) as uv
// FROM user_activity GROUP BY activity_type
```

**注意**：Prisma 不支持 groupBy 内 distinct count，需要用 `$queryRaw` 原生 SQL。

### 4.3 复玩查询

```typescript
const retention = await this.prisma.$queryRaw`
  SELECT 
    COUNT(*) as total_users,
    SUM(CASE WHEN visit_count >= 2 THEN 1 ELSE 0 END) as returning_users
  FROM (
    SELECT user_id, COUNT(*) as visit_count
    FROM page_visit
    WHERE user_id IS NOT NULL
    GROUP BY user_id
  )
`;
```

### 4.4 趋势查询

```typescript
const trend = await this.prisma.$queryRaw`
  SELECT 
    DATE(created_at) as date,
    COUNT(*) as pv,
    COUNT(DISTINCT user_id) as uv
  FROM page_visit
  WHERE created_at >= ${startDate}
  GROUP BY DATE(created_at)
  ORDER BY date ASC
`;
```

## 六、风险与回滚

| 风险 | 严重度 | 缓解 |
|------|--------|------|
| `$queryRaw` SQL 注入 | 低 | 全部使用参数化查询 |
| 大表 groupBy 慢查询 | 中 | 加 createdAt 索引（已有）+ 限制查询范围（7/30 天） |
| 前端 overview 重构影响其他 tab | 低 | 只改 overview tab 内容，不动 tab 切换逻辑 |
| 部署回滚 | 低 | 每阶段独立 commit，可独立回滚 |
