# E86｜"改了代码≠功能通了"端到端验证门禁

## 触发条件
修复 bug / 改了代码 / 编译通过 / 功能不生效 / 降级 / fallback

## 教训
修复 bug 后只验证编译通过（tsc --noEmit），没有验证功能端到端生效。spawn bug 存在数月未被发现，因为只验证了编译，没有验证 Python CLI 是否真正返回数据。

## 反例
`spawn()` → `spawnSync()` 后只跑 tsc --noEmit，没有实际调用 Python CLI 验证数据返回。结果：代码编译通过但 Python 引擎永远降级到 iztro。

## 判断规则
修复 bug 后必须执行三层验证：
1. **编译验证**：tsc --noEmit 通过
2. **功能验证**：端到端调用验证功能生效（不只是编译通过）
3. **回归验证**：确认修复没有引入新问题

1 | 跨场景：是 | 置信度：high
