## 一、接口文档

### 1.1 紫微斗数分析接口（已有，无变更）

**端点**：`POST /api/v1/consult/analyze`

**请求体**（ziwei 路由）：

```typescript
interface ZiweiInput {
  birthDate: string;      // "1990-05-15"
  birthTime: string;      // "08:00"
  gender: 'male' | 'female';
  birthPlace?: string;
  question?: string;      // 默认 "请看整体紫微命盘格局"
  focusArea?: string;
  lang?: string;
  targetYear?: number;    // 流盘年份（新增前端透传）
  targetMonth?: number;   // 流盘月份
  targetDay?: number;     // 流盘日
  targetHour?: number;    // 流盘时
}
```

**响应体**：

```typescript
interface ZiweiResult {
  solarDate: string;
  lunarDate: string;
  chineseDate: string;
  gender: string;
  time: string;
  timeRange: string;
  sign: string;
  zodiac: string;
  soul: string;
  body: string;
  fiveElementsClass: string;
  earthlyBranchOfSoulPalace: string;
  earthlyBranchOfBodyPalace: string;
  palaces: ZiweiPalaceData[];
  liupan?: {               // ⚠️ 新增前端消费
    daxian: DaxianData[];  // 大限
    liunian: LiunianData[]; // 流年
    liuyue?: LiuyueData[];  // 流月
    liuri?: LiuriData[];    // 流日
    liushi?: LiushiData[];  // 流时
  };
}
```

### 1.2 飞星数据结构（已有，无变更）

```typescript
interface ZiweiPalaceData {
  index: number;
  name: string;           // "命宫" / "兄弟" / "夫妻" ...
  isBodyPalace: boolean;
  heavenlyStem: string;   // "甲" / "乙" ...
  earthlyBranch: string;  // "子" / "丑" ...
  majorStars: Array<{
    name: string;
    type: string;
    brightness?: string;  // "庙" / "旺" / "得" / "利" / "平" / "不" / "陷"
    mutagen?: string;     // "禄" / "权" / "科" / "忌" ← 四化飞星
  }>;
  minorStars: Array<{ name: string; type: string; brightness?: string; mutagen?: string }>;
  adjectiveStars: Array<{ name: string; type: string }>;
  decadal?: { range: [number, number]; heavenlyStem: string; earthlyBranch: string };
  ages?: number[];
}
```

### 1.3 FeixingChart 组件接口（新增）

```typescript
// 文件：app/src/components/ziwei/FeixingChart.tsx
```
