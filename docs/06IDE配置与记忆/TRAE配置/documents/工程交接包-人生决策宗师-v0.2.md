## 4. 接口文档

### 4.1 前端 → 后端 API

| 接口 | 方法 | 鉴权 | 请求参数 | 响应 | 错误码 | 调用方 |
|---|---|---|---|---|---|---|
| `/api/v1/consult/analyze` | POST | Bearer Token | CalcInput (见下方) | CalcResult | 400/401/500 | 前端 api/client.ts |

**CalcInput 请求体**：

```typescript
{
  routeType: 'liuren' | 'ziping' | 'quming' | 'qimen' | 'liuyao' | 'ziwei',
  question: string,
  askTime?: string,
  askLocation?: string,
  birthDate?: string,       // "1990-06-15"
  birthTime?: string,       // "14:00"
  birthPlace?: string,      // "北京市"
  gender?: 'male' | 'female',
  timeUnknown?: boolean,
  hexagramCode?: string,
  surname?: string,
  givenName?: string,
  parentWish?: string,
  avoidChars?: string[],
  targetYear?: number,      // 流盘目标年份
  targetMonth?: number,
  targetDay?: number,
  targetHour?: number
}
```

**ZiweiResult 响应体**（routeType='ziwei' 时）：

```typescript
{
  solarDate: string,
  lunarDate: string,
  chineseDate: string,
  gender: string,
  time: string,
  timeRange: string,
  sign: string,
  zodiac: string,
  soul: string,
  body: string,
  fiveElementsClass: string,
  earthlyBranchOfSoulPalace: string,
  earthlyBranchOfBodyPalace: string,
  palaces: ZiweiPalaceData[],
  liupan?: {              // 仅 targetYear 有值时返回
    daxian: Array<{
      index: number;
      ming_gong_pos: number;
      tiangan: number; tiangan_name: string;
      dizhi: number; dizhi_name: string;
      age_start: number; age_end: number;
      sihua: any;
      gong_names: number[];
    }>;
    liunian: Array<{
      year: number;
      ming_gong_pos: number;
      tiangan: number; tiangan_name: string;
      dizhi: number; dizhi_name: string;
      sihua: any;
      liuchang_pos: number;
      liuqu_pos: number;
    }>;
    xiaoxian?: any;
    liuyue?: any;
    liuri?: any;
    liushi?: any;
  }
}
```

### 4.2 后端 → Python CLI 接口

| 接口 | 方法 | 请求参数 | 响应 |
|---|---|---|---|
| `paipan_cli.py` | CLI spawn | `python paipan_cli.py <year> <month> <day> <hour> <sex> [options]` | JSON（stdout） |

**位置参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| year | int | 公历年份 |
| month | int | 公历月份 (1-12) |
| day | int | 公历日期 (1-31) |
| hour | int | 时辰 (0=子时, ..., 11=亥时) |
| sex | int | 性别 (1=男, 2=女) |

**可选参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| --liupan-year | int | - | 流年年份 |
| --liupan-month | int | - | 流月月份 |
| --liupan-day | int | - | 流日日期 |
| --liupan-hour | int | - | 流时时辰 |
| --feixing | flag | false | 启用飞星计算 |
| --config | str | default | 配置预设名称 |
| --pretty | flag | false | 格式化 JSON 输出 |
