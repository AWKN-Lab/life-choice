2. 路由/页面接线：确认组件在 JSX 中被渲染

### E92.3 核心规则（v2 新增，4 条）

#### 规则 4：扫描必须全量覆盖
- 孤儿扫描必须用 `Glob **/*.tsx` 列全量清单，不能只扫部分子目录
- 不能依赖 search agent 的"局部扫描"——agent 可能只扫了 3 个子目录就报告"全部接入"
- 验证方法：Glob 全量清单 vs 已接入清单，差集 = 遗漏

#### 规则 5：区分预装库和项目组件
- shadcn/ui 等预装组件库未使用是正常的，不算孤儿
- 只对"项目特定组件"（components 根级、业务子目录）做孤儿判定
- search agent 输出必须过滤预装库后再报告

#### 规则 6：禁止 as any 绕过 props 类型
- 接入组件时必须读取组件实际 props 类型定义
- 禁止用 `as any` 绕过类型不匹配
- tsc 通过 ≠ 运行时安全

#### 规则 7：重复文件必须先清理再接入
- 同名组件必须先确认哪个是正式版本
- 删除非正式版本，只接入正式版本
- 不能两个都接入
