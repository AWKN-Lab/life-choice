## 3. 假设与决策

### 3.1 关键假设

1. **metaphysics.db passages 表 content 字段为已切分片段**(基于 _u11_quality_eval.py 的 avg_len 50-160 字统计)
   - 若假设错误(S1 发现是完整文本),S2 需增加切分逻辑
2. **15 本的 system_type 可通过文本关键词分类**(复用 _extract_recovered.detect_system_type_from_text)
   - 若道系列可能归为 bazi 或 ziwei(需验证)
3. **服务器磁盘可用 2.9GB 足够容纳 1.6GB embeddings.npy 替换**
   - 替换后旧文件删除,净增约 400MB,2.9GB - 400MB = 2.5GB 剩余
4. **PM2 重启后 mmap 模式仍可用**(KNOWLEDGE_USE_MMAP=1 已部署)

### 3.2 关键决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 数据源 | metaphysics.db 直接抽取 | 15 本数据已在 db 中,无需从 docx 重新提取 |
| 切分策略 | 根据 S1 结果决定 | 避免重复切分或漏切 |
| 分类策略 | 复用 detect_system_type_from_text | 保持与现有索引分类一致 |
| embeddings 生成 | 全量重新生成 TF-IDF | 增量生成复杂度高,全量仅 6-10 分钟 |
| 部署方式 | scp + PM2 restart | 复用 U8 部署流程 |
| OOM 防护 | KNOWLEDGE_USE_MMAP=1 | 服务器内存仅 483MB,必须 mmap |
