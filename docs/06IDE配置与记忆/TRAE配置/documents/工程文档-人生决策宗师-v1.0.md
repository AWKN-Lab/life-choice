## 一、项目概述

### 1.1 产品定位

面向中文用户的 AI 命理决策咨询平台，核心能力：紫微斗数排盘 + AI 解读 + 决策建议。

### 1.2 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | React + Vite + TypeScript | React 18 / Vite 7 |
| 后端 | NestJS + TypeScript | — |
| 排盘引擎 | Python（ziwei.py + liupan.py + feixing.py + geju_engine.py） | Python 3.9+ |
| 农历转换 | sxtwl | v2+ |
| 降级排盘 | iztro | — |
| 数据库 | Supabase (PostgreSQL) | — |
| LLM | 通过 LlmProvidersService 统一网关 | — |

## 二、接口文档

### 2.1 咨询分析接口

**路由**：`POST /api/v1/consult/analyze`

**请求体**：

```typescript
interface CalcInput {
  routeType: 'liuren' | 'ziping' | 'quming' | 'qimen' | 'liuyao' | 'ziwei';
  question: string;
  askTime?: string;          // ISO 8601
  askLocation?: string;      // "北京市"
  birthDate?: string;        // "1990-06-15"
  birthTime?: string;        // "14:00"
  birthPlace?: string;       // "北京市"（用于真太阳时，暂未实现）
  gender?: 'male' | 'female';
  timeUnknown?: boolean;
  hexagramCode?: string;     // 六爻专用
  surname?: string;          // 取名专用
  givenName?: string;
  parentWish?: string;
  avoidChars?: string[];
  targetYear?: number;       // 流盘目标年份
  targetMonth?: number;
  targetDay?: number;
  targetHour?: number;
}
```

**响应体**：

```typescript
interface CalcResult {
  routeType: string;
  calcData: LiurenResult | ZiweiResult | QimenResult | LiuyaoResult | any;
  summary_core: string;
  risk_tags: string[];
  action_tags: string[];
  time_window: string[];
  evidence_tags: string[];
}
```

### 2.3 Python CLI 接口

**入口**：`python paipan_cli.py <year> <month> <day> <hour> <sex> [options]`

**位置参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| year | int | — | 公历年份 |
| month | int | 1-12 | 公历月份 |
| day | int | 1-31 | 公历日期 |
| hour | int | 0-11 | 时辰（0=子时, 1=丑时, ..., 11=亥时） |
| sex | int | 1-2 | 性别（1=男, 2=女） |

**可选参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| --liupan-year | int | - | 流年年份 |
| --liupan-month | int | - | 流月月份 |
| --liupan-day | int | - | 流日日期 |
| --liupan-hour | int | - | 流时时辰 |
| --feixing | flag | false | 启用飞星计算 |
| --config | str | default | 配置预设名称 |
| --pretty | flag | false | 格式化 JSON 输出 |

**输出示例**：

```json
{
  "solar_date": "1990-6-15",

      "dizhi": 2,
      "stars": ["紫微", "天相"],

  ],
  "liupan": {
    "daxian": [...],
    "liunian": [...]

    "zihua_lixin": [...],
```
