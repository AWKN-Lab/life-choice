#### 1.1.1 能力定义

```markdown
## 决策框架模块

### 能力名称
4步决策框架 (Decision Framework 4-Step)

### 能力描述
通用决策指导方法论，适用于任何需要做决定的任务

### 触发条件
- 用户请求做决定/选择/判断
- 需要评估多个选项
- 面临不确定性

### 触发词
决定、选择、怎么办、如何选、哪个好、判断

### 执行流程
1. 理解需求 → 明确决策目标和约束
2. 识别风险 → 列出选项并评估风险
3. 生成方案 → 提供2-3个可行方案
4. 评估决策 → VFM矩阵打分，推荐最优

### 输出格式
- 推荐方案及理由
- 备选方案
- 风险提示
- 下一步行动建议

### 整合位置
天火智能体人格底座 → 决策模块
```

#### 1.1.2 VFM评估矩阵

```markdown
## VFM评估 (Value-Feasibility-Maintainability)

### 评分维度
| 维度 | 权重 | 评分标准 |
|------|------|----------|
| Value (价值) | 40% | 1-10分，用户价值大小 |
| Feasibility (可行性) | 35% | 1-10分，技术/资源可行性 |
| Maintainability (可维护性) | 25% | 1-10分，长期维护成本 |

### 计算公式
总分 = V×0.4 + F×0.35 + M×0.25

### 判定阈值
- ≥7.5: 推荐执行
- 5-7.5: 可考虑，需优化
- <5: 暂不推荐
```

1. 快速评估任务范围
2. 匹配L1-L4分类
3. 根据分类选择处理策略
