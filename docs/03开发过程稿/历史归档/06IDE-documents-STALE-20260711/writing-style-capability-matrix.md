# 写作风格能力矩阵

> 三套成熟写作方法论 × 人生决策宗师输出场景的交叉映射

## 一、输出场景分类

本项目 LLM 输出按"长度 + 目的"分为 5 类：

| 类型 | 代表模块 | 长度 | 目的 | 关键要求 |
|------|---------|------|------|---------|
| **定性判断** | 六壬/六爻/八字断事结论 | 50-150字 | 给用户一个明确的吉凶判断 | 敢下判断、不模棱两可、有记忆点 |
| **每日提醒** | 醒神早贴 | 300-500字 | 今天的行动指南 | 可行动、具体、有人情味 |
| **深度分析** | 深入推演 | 800-1500字 | 从排盘数据推导人生建议 | 有逻辑链、有证据、有升华 |
| **图表注解** | K线图交叉点标签 | 2-10字 | 极短标签 | 精准、不吓人 |
| **术语解释** | 各模块中的十神/课体/神煞解释 | 20-50字 | 让小白看懂 | 白话翻译、不堆术语 |

## 三、统一能力标签（合并三套后的 12 项核心能力）

| 标签 | 来源 | 一句话 |
|------|------|--------|
| **C1 活人感** | 卡兹克 | 读起来像真人在聊天，不是 AI 在输出信息 |
| **C2 去 AI 味** | 卡兹克+爆款 | 禁用"首先其次""综上所述""说白了""意味着" |
| **C3 敢下判断** | 卡兹克 | 不模棱两可，吉就是吉凶就是凶，有理由 |
| **C4 意象转译** | 吴梦知 | 抽象概念翻译为具象画面（"吉"→"灯塔亮了"） |
| **C5 金句收尾** | 吴梦知+爆款 | 每段输出结尾有一句让人想记下来的短句 |
| **C6 四字对仗** | 吴梦知 | 关键标签用四字凝练（"披荆为冠，斩棘为袍"） |
| **C7 痛点共情** | 吴梦知 | 先承认用户的处境是真实的，再给出方向 |
| **C8 私人视角** | 卡兹克 | 用"我觉得""我也经历过"而非"根据命理分析" |
| **C9 节奏控制** | 卡兹克 | 长短句交替，关键句独立成段 |
| **C10 知识降维** | 卡兹克 | 术语后面紧跟白话翻译，像聊着聊着掏出来的 |
| **C11 结构模板** | 爆款 | 钩子→痛点→核心→金句→赋权的推进逻辑 |
| **C12 质量自检** | 卡兹克+爆款 | L1-L4 四层质检 + 7 轮编辑法 |

```
  C1 活人感 + C10 知识降维 + C2 去AI味
```

| 醒神早贴 | C10（算法兜底有术语翻译） | C1 活人感、C7 痛点共情、C8 私人视角 | **高** |

## 六、实施优先级建议

