## 1. 知识库数据源概览

### 1.1 数据源层级（5 级）

| 层级 | 来源 | 位置 | 数量 | 说明 |
|------|------|------|------|------|
| L1 | `knowledge-base/` 目录 | `awkn-life-backend/src/knowledge-base/` | 11 JSON（liuren） | 东方玄学知识库主目录，当前仅 liuren 子目录有结构化 JSON |
| L2 | `calc-engine/data/` | `awkn-life-backend/src/calc-engine/data/` | **13 JSON** | 算法引擎数据，含干支/纳音/神煞/十神/大运等 |
| L3 | `lib/atom-tools/` | `awkn-life-backend/src/lib/atom-tools/` | 30+ TS 文件 | 原子工具库（八字/决策/紫微），含静态数据与计算逻辑 |
| L4 | Prisma 数据库 | `awkn-life-backend/prisma/` | **33 个模型** | SQLite prod.db，全量业务数据 |
| L5 | 前端 `data/` 目录 | `app/src/data/` | 5 组静态数据 | clauses/followups/scenarios/agent-intro-messages/l1-loader |

### 1.2 合并逻辑

**核心服务**：`knowledge-retriever.service.ts`（Orchestrator 流水线中的知识检索层）

```
ConsultModule.handleConsult()
  │
  ├── CalcEngineService.calculate() ──→ calc-engine/data/*.json（L2 静态数据）
  │     ├── bazi-engine/ ──→ 四柱排盘 / 五行分析 / 十神计算 / 神煞判定 / 大运推算 / 真太阳时
  │     └── naming-engine/ ──→ 康熙笔画 / 五格数理 / 三才配置 / 生肖禁忌
  │
  ├── KnowledgeRetriever.retrieve() ──→ knowledge-base/liuren/*.json（L1 知识库）
  │     ├── 向量搜索（Chroma DB） ──→ 经典文本 passages
  │     ├── 关键词搜索 ──→ JSON 规则匹配
  │     └── 知识图谱查询 ──→ knowledge_graph.json
  │
  ├── AgentPromptBuilder.build() ──→ *-agent/prompts/*.md（提示词资产）
  │
  └── LLMProvider.generate() ──→ 5 Provider 并行竞速
        ├── SenseNova（商汤日日新）
        ├── DeepSeek
        ├── Doubao（字节豆包）
        ├── MiniMax
        └── DeepSeek-Direct（直连备用）
```

- 知识库检索：`KnowledgeRetriever` 统一调度，支持向量搜索 + 关键词搜索 + 知识图谱
- 算法引擎：`CalcEngineService` 独立计算，结果写入 `ConsultRecord.calcResult`
- LLM 生成：`ZhangbanshanScheduler` 调度 5 Provider，结果写入 `ConsultRecord.llmResult`

## 2. 算法引擎资产清单

### 2.1 八字引擎

**位置**：`awkn-life-backend/src/calc-engine/bazi-engine/`

| 文件 | 用途 | 核心功能 |
|------|------|---------|
| `core/bazi-data.service.ts` | 八字数据服务 | 天干地支/纳音/神煞/十神查表 |
| `core/solar-terms.ts` | 节气计算 | 24 节气精确推算（真太阳时校正） |
| `../bazi-calculator-wrapper.ts` | 八字计算器包装 | 四柱排盘 / 五行分析 / 身旺判断 / 喜忌用神 |
| `../calculators.ts` | 计算器入口 | 统一调度各模块计算 |
| `../calc-engine.service.ts` | 引擎服务 | 对外暴露的 NestJS Service |
| `__tests__/bazi-golden.spec.ts` | Golden 测试 | 八字计算正确性验证 |
| `__tests__/bazi-data.spec.ts` | 数据测试 | 数据查表正确性验证 |
| `__tests__/jieqi-validation.spec.ts` | 节气验证 | 节气计算精度验证 |

**八字引擎核心计算链**：

```
用户输入（出生时间+地点）
  │
  ├── 真太阳时校正 ──→ correctedHour / city
  ├── 四柱排盘 ──→ yearGanZhi / monthGanZhi / dayGanZhi / timeGanZhi
  │     ├── 年柱：农历年 → 天干地支
  │     ├── 月柱：五虎遁法（年干 → 月柱）
  │     ├── 日柱：儒略日算法
  │     └── 时柱：五鼠遁法（日干 → 时柱）
  ├── 五行分析 ──→ wuXingDist（木/火/土/金/水分布）
  ├── 身旺判断 ──→ shenWang / shenWangScore
  ├── 喜忌用神 ──→ xiYongShen（喜/用/忌神）
  ├── 十神计算 ──→ shiShen（日干与他干阴阳生克配对）
  ├── 神煞判定 ──→ shenSha（吉凶神煞列表）
  ├── 大运推算 ──→ qiYunAge / isShunYun
  ├── 胎元命宫 ──→ taiYuan / mingGong
  └── 纳音五行 ──→ naYinYear/Month/Day/Time
```
