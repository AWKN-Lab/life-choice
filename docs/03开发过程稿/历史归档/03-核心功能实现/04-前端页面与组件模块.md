### FrontdeskChat 通用对话前台

**目录**：`app/src/components/frontdesk/`

**设计理念**：合并取名/问事前台为单一通用组件，消除重复代码。

| 文件 | 说明 |
|------|------|
| `FrontdeskChat.tsx` | 核心组件，通过 `mode` prop 切换 naming/question，`renderAs` 切换 modal/page |
| `types.ts` | 类型定义：`FrontdeskMode`、`FrontdeskChatProps`、`FrontdeskConfig`、`FrontdeskStep` |
| `frontdeskConfigs.ts` | 模式配置：naming 蓝色系，question 紫色系 |

**Props**：
```typescript
interface FrontdeskChatProps {
  mode: 'naming' | 'question';
  onClose?: () => void;
  renderAs?: 'modal' | 'page';
}
```

**naming 模式**：
- 三步流程：对话 → 表单详情 → 宝宝出生信息
- 快捷选项：宝宝取名 / 成人改名 / 起字号
- 偏好标签：古典 / 现代 / 五行 / 笔画
- 提交时写入 source_entry='naming'、naming_preferences、unlock_status

**question 模式**：
- 单步流程：输入 → 意图识别 → 路由 → 跳转
- 快捷建议：4 个预设问事场景
- 意图分类：事业 / 财运 / 健康 / 婚姻 / 官非 / 出行
- 提交时写入 source_entry='question'、question_intent、unlock_status

**i18n**：
- 中文常量和用户消息已全部迁移到 locales 翻译文件
- `TYPE_OPTIONS`、`FOLLOWUP_QUESTIONS`、`CHAT_PREFERENCES` 均通过 i18n key 获取
- 英文/泰文翻译文件已同步更新

**路由**：
```typescript
// App.tsx — 两种渲染模式
<Route path="/naming" element={<FrontdeskChat mode="naming" renderAs="page" />} />
<Route path="/question" element={<FrontdeskChat mode="question" renderAs="page" />} />
```
