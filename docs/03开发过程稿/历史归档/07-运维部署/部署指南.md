### 部署脚本

```bash
#!/bin/bash
set -e

echo "=== 人生决策宗师 一键部署 ==="

echo "[1/7] 拉取最新代码..."
cd /opt/awkn-life
git pull origin main

echo "[2/7] 安装后端依赖..."
cd awkn-life-backend
npm ci --production

echo "[3/7] 构建后端..."
npm run build

echo "[4/7] 数据库迁移..."
npx prisma migrate deploy

echo "[5/7] 安装前端依赖并构建..."
cd ../../app  # 本地构建后上传
npm ci
npm run build

echo "[6/7] 重启后端服务..."
cd /opt/awkn-life
pm2 restart awkn-life-backend || pm2 start ecosystem.config.js

echo "[7/7] 重载 Nginx..."
sudo nginx -t && sudo nginx -s reload

echo "=== 部署完成 ==="
pm2 status
```

```dockerfile
FROM node:20-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .

FROM node:20-alpine AS runner

WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
```

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 502 Bad Gateway | 后端未启动或端口不匹配 | 检查 `pm2 status`，确认 3002 端口（不是 3000） |
| 前端显示兜底文案 | 后端 API 不可达 | `curl http://127.0.0.1:3002/api/v1/health` 确认后端存活 |
| SSL 证书过期 | Let's Encrypt 证书 90 天有效期 | `sudo certbot renew` |
| 前端白屏 | 构建产物路径错误 | 检查 nginx root/alias 指令指向 `/www/wwwroot/awkn-lab/life/` |
| API 超时 | LLM Provider 响应慢 | 检查 fallback 日志，确认网络；5 Provider 并行竞速 |
| 数据库锁定 | SQLite 并发写入 | 考虑迁移至 PostgreSQL |
| 磁盘空间不足 | 当前已用 81% | 清理 nginx 备份配置（50+ 个 .bak 文件）和旧日志 |

## 历史事故记录

### 2026-06-05 端口不匹配导致 API 全部不可用

- **现象**：前端显示"已生成本地初步结果"兜底文案，所有 API 调用失败
- **根因**：后端 .env PORT=3000，ecosystem.config.js PORT=3000，但 nginx 反代指向 3002
- **修复**：将 .env 和 ecosystem.config.js 的 PORT 从 3000 → 3002
- **验证**：`curl https://awkn.cn/life/api/v1/health` → `{"code":0,"message":"ok"}`
- **教训**：部署时必须确认 nginx upstream 端口与后端实际监听端口一致
