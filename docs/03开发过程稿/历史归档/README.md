# Legacy 文档归档

> 本目录存放人生决策宗师项目的历史文档，仅作归档与溯源用途。
> 最后治理日期：2026-06-05

---

## 目录定位

`docs/legacy/` 是人生决策宗师项目历史文档的**只读归档区**。所有文档在迁入本目录后，不再作为开发或决策的依据，仅用于：

- 溯源历史决策与设计意图
- 回溯某次迭代的产品/技术背景
- 新成员了解项目演进脉络

**如需引用 legacy 文档中的内容，必须先确认其状态（见下方分类），并以权威替代文档为准。**

---

## 状态分类

| 状态 | 含义 | 使用指引 |
|------|------|----------|
| **ACTIVE** | 仍有效的操作文档，当前仍在执行 | 可直接引用，但需关注是否有更新版本 |
| **REFERENCE** | 历史参考，仍有参考价值但不再作为执行依据 | 可查阅背景信息，不作为决策依据 |
| **DEPRECATED** | 已废弃，内容过时或方案已弃用 | 不建议引用，仅供了解历史 |
| **MIGRATE_TO** | 已有新文档替代，内容已迁移 | **必须使用权威替代文档**，本文件仅保留归档 |

---

## 如何查找文档

1. **按主题查找**：参考下方目录结构，进入对应子目录
2. **按状态查找**：查阅 [INDEX.md](./INDEX.md)，按状态列筛选
3. **按替代关系查找**：INDEX.md 的「权威替代文档」列指向现行文档

## 治理规则

- 每篇 legacy 文档头部必须包含状态块（格式见 INDEX.md 说明）
- 状态变更需更新 INDEX.md 和文档头部状态块
- 新归档文档需同步更新 INDEX.md
- 每季度核验一次状态，更新「最后核验日期」
