### 2.2 系统提示词核心结构（liuren-system-prompt.md）

```
1. 角色定义
   - 身份：大六壬专业分析助手
   - 能力边界：仅限大六壬领域，不做医疗/法律建议

2. 知识范围
   - 九宗门起课法
   - 毕法赋 100 条歌诀
   - 五层神煞体系
   - 金口诀/退命/择日专项

3. 输出规范
   - 结构化输出（课体→三传→神煞→断法→建议）
   - 置信度标注（高/中/低）
   - 免责声明

4. 交互约束
   - 不做确定性预测
   - 提供多角度解读
   - 引导用户理性参考
```

### 2.3 分析提示词模板（liuren-analysis-prompt.md）

```
分析流程：
1. 事件分类 → classifyEvent() 编码
2. 起课排盘 → 四课三传
3. 神煞标注 → 五层神煞
4. 课体判定 → 九宗门/课体
5. 毕法赋匹配 → 歌诀断法
6. 占类细则 → zhanlei-rules
7. 综合断法 → 多维度解读
8. 建议输出 → 行动参考
```

```

2. 取名规则
   - 八字喜用神确定
   - 五行补益配置
   - 音韵搭配（平仄/韵母）

3. 输出规范
   - 候选名字（3-5 个）
   - 五行分析
   - 音韵分析
   - 寓意解读
   - 综合评分
```
