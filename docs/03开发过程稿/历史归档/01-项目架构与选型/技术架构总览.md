# 人生决策宗师 — 技术架构总览

## 1. 架构概述

人生决策宗师采用**前后端分离**架构，前端为 React SPA 单页应用，后端为 NestJS API 服务。整体设计遵循以下原则：

| 原则 | 含义 |
|------|------|
| 简单优先 | 能用一行代码解决的不用两行，能用 SQLite 的不引入 PG |
| 渐进增强 | 核心功能先跑通，动画/3D 等体验层逐步叠加 |
| 防御性编程 | 外部 API 调用必须有超时、重试、降级；用户输入必须校验 |
| 可观测性 | 关键路径打日志，LLM 调用记耗时，异常自动上报 |

## 4. 后端模块架构

### 4.1 模块职责一览

| 模块 | 职责 | 关键能力 |
|------|------|---------|
| **consult** | 咨询路由与编排 | 路由分流（八字/六壬/六爻/奇门/取名）、结果拼装、追问上下文管理 |
| **calc-engine** | 命理计算引擎 | 八字排盘、六壬起课、真太阳时校正、干支历法转换 |
| **llm-gateway** | LLM 统一网关 | 多 Provider 路由、Prompt 模板管理、自动 failover、调用耗时统计 |
| **payment** | 支付服务 | 微信支付（JSAPI/H5）、支付宝支付、订单管理、回调验签 |
| **knowledge-base** | 知识库 | 八字/六壬 JSON 数据、神煞表、格局判定规则、术语解释 |
| **liuren-agent** | 六壬 Agent | 六壬专用提示词、课体分析、类象映射、断课逻辑 |
| **liuyao-agent** | 六爻 Agent | 六爻专用提示词、卦象分析、用神/忌神判定 |
| **qimen-agent** | 奇门 Agent | 奇门专用提示词、局数排盘、用神分析 |
| **quming-agent** | 取名 Agent | 取名专用提示词、五行喜忌、三才五格、音韵搭配 |

### 4.2 请求流转

```
用户请求
  │
  ▼
consult（路由分流）
  │
  ├── 八字咨询 ──► calc-engine（排盘）──► llm-gateway（解读）──► 结果拼装
  ├── 六壬咨询 ──► calc-engine（起课）──► liuren-agent ──► llm-gateway ──► 结果拼装
  ├── 六爻咨询 ──► liuyao-agent ──► llm-gateway ──► 结果拼装
  ├── 奇门咨询 ──► qimen-agent ──► llm-gateway ──► 结果拼装
  └── 取名咨询 ──► quming-agent ──► llm-gateway ──► 结果拼装
```

### 4.3 LLM 降级策略

```
请求进入 llm-gateway
  │
  ├── 1. 前2个 Provider 并行竞速
  │     ├── SenseNova（商汤，优先）
  │     └── DeepSeek（第二）
  │
  ├── 2. 两个都失败 → 串行尝试
  │     ├── Doubao（豆包，第三）
  │     ├── MiniMax（容灾）
  │     └── DeepSeek-Direct（兜底）
  │
  └── 全部失败 → 返回错误
```

> **2026-06-05 更新**：chatWithFallback 已改为前 2 个 Provider 并行竞速（Promise.allSettled），显著降低首响应延迟。chatWithUser 指定 Provider 失败后也会自动走 fallback 链。
