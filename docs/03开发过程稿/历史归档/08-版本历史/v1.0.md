## 一、项目概述

### 1.1 项目定位

**人生决策宗师**是一款AI命理咨询全栈应用，融合传统命理智慧（八字/六壬/奇门/六爻/取名）与现代AI技术，为用户在人生关键决策节点提供命理参考与理性分析。

### 1.2 核心价值

- **算法驱动**：八字排盘、六壬起课、真太阳时校准，算法可解释
- **LLM增强**：大模型推理，提供自然语言解读
- **证据追溯**：每条结论有sourceId，可追溯到算法证据
- **多端支持**：H5移动端 + Web管理后台

### 1.3 技术架构

```
用户层 → 前端(React+Vite) → 后端(NestJS) → LLM Providers
                                    ↓
                               数据库(PostgreSQL)
                                    ↓
                              命理知识库(JSON)
```
