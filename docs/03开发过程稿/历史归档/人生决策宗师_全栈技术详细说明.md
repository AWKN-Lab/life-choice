### 2.2 十一阶段详解

#### Phase 1：进入

**触发**：用户打开 H5 页面 `https://awkn.cn/life/`

**Landing 入口路径**：
```
/life/ → LandingPage（6个区块：Hero/Services/Process/Testimonials/About/Footer）
  → /life/ （HomePage，主入口）
    → /life/question（问事入口）
    → /life/naming（取名入口）
    → /life/shumiyuan（问人入口 — 枢密院）
```

**URL 参数注入**：
- `?token=xxx` → 从 URL 提取 token 写入 localStorage
- `?utm_source=poster&utm_medium=wechat` → UTM 追踪写入 utmStore
- `?lang=en` → 语言切换

**技术实现**：
- 前端：`store/utmStore.ts` 的 `initFromURL()` 在 store 初始化时自动提取并清理 URL 参数
- 后端：CORS 白名单 `https://awkn.cn, https://www.awkn.cn`

#### Phase 2：注册 / 登录

**邮箱/手机号登录**：
```
POST /api/v1/auth/register { email, password, nickname }
  → 创建 User 记录
  → JWT token 生成（7天过期）
  → 返回 { accessToken, user }

POST /api/v1/auth/login { email, password }
  → 验证密码（bcryptjs）
  → JWT token 生成
  → 返回 { accessToken, user }
```

**认证守卫策略**（`auth/guards/`）：

```
请求进入
  ├─ JwtAuthGuard（默认） → Bearer token → JWT 验证 → 401 或放行
  ├─ OptionalJwtAuthGuard → token 可选，匿名用户也可访问部分功能
  └─ AdminGuard → 检查 user.isAdmin === true
```

**关键数据表**：
- `User`：用户主表（email, phone, wxOpenId, nickname, gender, birthDate, birthTime, birthPlace, creditBalance, freeTrialUsed, isAdmin）

#### Phase 3：选择入口（三入口前台）

**FrontdeskChat 三入口设计**：

| 入口 | 路径 | mode | 路由目标 |
|------|------|------|---------|
| 问事 | `/question` | `question` | 子平/六壬/六爻/奇门路由 |
| 取名 | `/naming` | `naming` | 取名Agent（7阶段多轮对话） |
| 问人 | `/shumiyuan` | — | 枢密院三段式（speak→spread→bottom） |

**问事入口流程**：
```
用户输入问题 → FrontdeskChat（mode="question"）
  → intentRouter.routeIntent(question) — 关键词匹配 + 加权评分
  → 路由结果：{ route_type, need_clarify, required_fields, next_step, confidence }
  → 跳转 InfoPage 或直接生成结果
```

**取名入口流程**（7阶段多轮对话）：
```
type → surname → gender → expectation → style → analyzing → result
  │         │        │         │           │         │          │
  ▼         ▼        ▼         ▼           ▼         ▼          ▼
 宝宝/    姓氏    男/女    期望风格    诗意/现代   调用后端   展示结果
 成人/品牌                                           analyze
```

**问人入口流程**（枢密院三段式）：
```
ShumiyuanPage
  → Speak（说）— 用户描述人事困境
  → Spread（推演）— 张半山推演各方立场和可能走向
  → Bottom（断底）— 给出最实在的判断和建议
```

#### Phase 4：信息采集

**InfoPage 信息收集**：

| 路由类型 | 必填字段 | 可选字段 |
|---------|---------|---------|
| ziping / ziwei / quming | birthDate, birthTime, gender | birthPlace |
| liuren / liuyao / qimen | askTime, askLocation | — |

**表单组件**：
- `CitySelector` — 城市选择器（用于真太阳时校正）
- `FateDateChart` — 命运日期选择器
- `FateHourWheel` — 时辰转盘选择器
- `HourWheel` — 小时滚轮
- `ConfidenceRing` — 置信度环形指示器
- `WaitingSpinner` — 等待动画

**真太阳时校正**（`lib/solarTime.ts`）：
- 根据出生城市经度校正时区偏移
- 北京时间（东八区 120°E）→ 出生地真太阳时

#### Phase 5：计算引擎

**POST /api/v1/consult/analyze** — 一次调用完成算法计算：

```
请求体：{ routeType, question, birthDate, birthTime, birthPlace, gender, askTime, askLocation, lang }
  → CalcEngineService.calculate(routeType, inputData)
    → ziping: bazi-calculator-wrapper → 四柱排盘 + 五行分析 + 十神 + 神煞 + 大运
    → liuren: liuren-calculator → 六壬排盘 + 天将 + 四课 + 三传
    → quming: naming-calculator → 康熙笔画 + 五格数理 + 三才配置
    → qimen: @yhjs/dunjia → 奇门排盘
    → liuyao: 六爻排盘
    → ziwei: 紫微排盘
  → 返回 calcResult（JSON）
```

#### Phase 6：LLM 生成

**5 Provider 并行竞速**（详见第5章）：

```
Promise.any([SenseNova, DeepSeek, Doubao, MiniMax, DeepSeek-Direct])
  → 第一个成功返回
  → QualityGate 质量检查（qualityScore 0-100）
  → 全部失败则 fallback 到 chatWithUser（单 Provider 重试）
```

### 5.1 5 Provider 并行竞速

**chatWithFallback 逻辑**（`llm-gateway/llm-gateway.service.ts`）：
```typescript
async chatWithFallback(prompt: string, options?: ChatOptions): Promise<ChatResult> {
  // 5 Provider 并行竞速
  const results = await Promise.any([
    this.senseNovaChat(prompt, options),    // 优先
    this.deepSeekChat(prompt, options),      // 第二
    this.doubaoChat(prompt, options),        // 第三
    this.miniMaxChat(prompt, options),       // 第四
    this.deepSeekDirectChat(prompt, options), // 兜底
  ]);

  // 全部失败则 fallback
  if (!results) {
    return this.chatWithUser(prompt, options); // 单 Provider 重试
  }

  return results;
}
```
