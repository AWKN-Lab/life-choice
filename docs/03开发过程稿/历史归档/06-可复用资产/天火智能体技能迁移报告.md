# 天火智能体技能迁移报告

## 概述

本报告梳理「人生决策宗师」项目中天火智能体的技能资产，按迁移优先级分为两大类别：

| 类别 | 定义 | 迁移策略 |
|------|------|----------|
| Category 1 | 核心能力 — 适合整合到天火智能体人格底座 | 直接内化为人格底座模块 |
| Category 2 | 专业技能 — 独立算法与知识体系 | 以技能插件形式挂载，按需调用 |

## Category 1：天火智能体核心能力

### 1.1 决策框架体系

天火智能体的决策框架是其最核心的能力底座，所有咨询场景均基于此框架运行。

#### 四步决策框架

```
Step 1: 现状澄清 → 明确用户真实处境与核心矛盾
Step 2: 选项生成 → 基于命理信息与用户约束，生成可行选项
Step 3: 优劣推演 → 对每个选项进行多维度推演（时间/资源/风险）
Step 4: 决策建议 → 给出倾向性建议 + 边界声明
```

#### VFM 评估模型

| 维度 | 全称 | 含义 |
|------|------|------|
| V | Value | 选项的核心价值收益 |
| F | Feasibility | 选项的可行性评估 |
| M | Match | 选项与用户命理特征的匹配度 |

评估流程：

```typescript
interface VFMEvaluation {
  value: number;       // 0-10 分
  feasibility: number; // 0-10 分
  match: number;       // 0-10 分
  weightedScore: number; // V*0.3 + F*0.3 + M*0.4
}
```

#### 任务分类体系（L1-L4）

| 等级 | 类型 | 响应策略 | 示例 |
|------|------|----------|------|
| L1 | 简单查询 | 直接回答 | "今天适合搬家吗" |
| L2 | 常规咨询 | 框架分析 + 建议 | "今年事业运势如何" |
| L3 | 复杂决策 | 多选项推演 + VFM评估 | "两个offer怎么选" |
| L4 | 人生重大决策 | 全维度分析 + 长期推演 | "是否应该转行" |

#### ADL 防退化机制

ADL（Anti-Dependency Loss）防止用户对智能体产生过度依赖：


### 1.2 多 Provider Fallback 机制

天火智能体采用三级 LLM Provider 降级策略，确保服务可用性：

```
┌─────────────────────────────────────────────┐
│            请求入口                          │
├─────────────────────────────────────────────┤
│  Primary: 豆包 (Doubao)                     │
│  ├─ 模型: doubao-pro-32k                    │
│  ├─ 超时: 180s                              │
│  ├─ 适用: 复杂推理、长文本解读               │
│  └─ 失败 ↓                                  │
│                                             │
│  Secondary: MiniMax                         │
│  ├─ 模型: abab6.5s-chat                     │
│  ├─ 超时: 120s                              │
│  ├─ 适用: 中等复杂度任务                     │
│  └─ 失败 ↓                                  │
│                                             │
│  Tertiary: OpenAI                           │
│  ├─ 模型: gpt-4o-mini                       │
│  ├─ 超时: 60s                               │
│  └─ 适用: 简单任务兜底                       │
└─────────────────────────────────────────────┘
```

降级判定逻辑：

```typescript
async function callWithFallback(prompt: string): Promise<LLMResponse> {
  const providers = [
    { name: 'doubao', timeout: 180000, handler: callDoubao },
    { name: 'minimax', timeout: 120000, handler: callMiniMax },
    { name: 'openai', timeout: 60000, handler: callOpenAI },
  ];

  for (const provider of providers) {
    try {
      const response = await withTimeout(
        provider.handler(prompt),
        provider.timeout
      );
      logFallback(provider.name, 'success');
      return response;
    } catch (error) {
      logFallback(provider.name, 'failed', error);
      continue;
    }
  }
  throw new Error('All LLM providers unavailable');
}
```

## Category 2：awkn-programmer 技能体系

### 2.1 八字排盘算法

八字排盘是天火智能体的核心专业技能，基于中国传统命理学实现。

算法流程：

```
输入: 出生时间(公历) + 出生地(经度)
  ↓
Step 1: 真太阳时校准 → 将公历时间转为真太阳时
  ↓
Step 2: 转换为农历 → 公历转农历日期
  ↓
Step 3: 年柱计算 → 以立春为界，推算年干支
  ↓
Step 4: 月柱计算 → 以节气为界，推算月干支
  ↓
Step 5: 日柱计算 → 查表或算法推算日干支
  ↓
Step 6: 时柱计算 → 根据日干推时干支
  ↓
输出: 四柱八字(年柱/月柱/日柱/时柱)
```

核心数据结构：

```typescript
interface BaZiResult {

  shensha:     string[];
```

### 2.2 六壬起课算法

大六壬起课算法实现传统三传四课的完整推演。

```
输入: 占问时间 + 占问事项
  ↓
Step 1: 确定月将 → 根据节气确定当月月将
  ↓
Step 2: 确定占时 → 根据占问时间确定地支
  ↓
Step 3: 起天地盘 → 月将加占时，排天地盘
  ↓
Step 4: 起四课 → 根据日干支推四课
  ↓
Step 5: 起三传 → 根据四课关系推初传/中传/末传
  ↓
Step 6: 配天将 → 根据贵人顺逆配十二天将
  ↓
输出: 四课 + 三传 + 天将 + 类神
```

### 2.3 真太阳时校准

真太阳时校准是八字排盘精度的关键前置步骤，将标准时间转换为当地真太阳时。

```typescript
interface TrueSolarTimeConfig {
  longitude: number;      // 出生地经度（东经度数）
  standardMeridian: number; // 标准时区中央经线（中国: 120°）
  equationOfTime: number; // 时差值（分钟）
}

function toTrueSolarTime(
  standardTime: Date,
  longitude: number
): Date {
  const stdMeridian = 120;
  const longitudeDiff = longitude - stdMeridian;
  const localTimeOffset = longitudeDiff * 4; // 每度4分钟

  const eot = getEquationOfTime(standardTime);
  const trueSolarOffset = localTimeOffset + eot;

  return new Date(standardTime.getTime() + trueSolarOffset * 60000);
}
```

### 2.5 取名算法（康熙笔画）

取名算法基于康熙字典笔画数，结合五行三才五格体系。

```
输入: 姓氏 + 性别 + 偏好(可选)
  ↓
Step 1: 姓氏康熙笔画查表
  ↓
Step 2: 计算三才配置（天格/人格/地格）
  ↓
Step 3: 确定五行喜用 → 根据八字五行缺失/喜用
  ↓
Step 4: 生成候选名字 → 匹配笔画数 + 五行属性
  ↓
Step 5: 五格评分 → 天格/人格/地格/外格/总格
  ↓
Step 6: 筛选排序 → 综合评分 + 音韵 + 寓意
  ↓
输出: 候选名字列表(含评分与解析)
```

## 禁止项清单

以下行为在天火智能体中严格禁止，任何场景均不可突破：

| 编号 | 禁止项 | 说明 | 违反后果 |
|------|--------|------|----------|
| P-01 | 禁止输出绝对化承诺 | 不得使用"一定""必定""百分之百"等绝对化表述 | 输出拦截 + 日志告警 |
| P-02 | 禁止杜撰经典引用 | 引用古籍必须可溯源，不得编造经文出处 | 输出拦截 + 知识库校验 |
| P-03 | 禁止省略"决策参考"边界 | 所有决策建议必须附带"仅供参考"边界声明 | 输出补全 + 审计记录 |
| P-04 | 禁止直接给投资建议 | 不得给出具体买卖建议，仅提供趋势参考 | 输出拦截 + 风控告警 |

护栏实现：

```typescript
const GUARDRAILS = [
```
