## 10. 推荐发布流程

### 阶段 A：生产事实冻结

```text
1. 保存 git status / HEAD / diff 清单
2. 保存当前 PM2、端口、Nginx、环境变量名
3. 保存数据库和构建产物哈希
4. 创建数据库和当前产物回滚点
5. 确认磁盘空间
```

### 阶段 B：独立构建

在生产目录之外进行：

```text
1. 基于明确源码快照创建验证目录
2. 使用锁文件安装依赖
3. prisma generate
4. typecheck
5. test
6. build
7. 独立端口启动
8. 使用数据库副本验证迁移
```

### 阶段 C：发布

```text
1. 原子替换后端 dist
2. 原子替换前端静态目录
3. 按授权执行数据库迁移
4. 重启目标 PM2 进程
5. 完成接口和用户链路烟测
6. 观察日志和进程稳定性
```

### 阶段 D：回滚

任一硬闸门失败：

```text
1. 恢复旧 dist
2. 恢复旧前端目录
3. 必要时恢复数据库备份
4. 重启 PM2
5. 重跑健康检查
```
