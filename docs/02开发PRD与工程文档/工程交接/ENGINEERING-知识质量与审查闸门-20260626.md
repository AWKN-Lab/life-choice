#### 3.3.2 P2.2 constitution.md 审查规则章节

在"## 约束"章节后追加：

```markdown
## 审查规则

> 目的：消除治理体系"自写-自执行-自验收-自闭环"的递归空转，重演 H-002 根因。

### R-1 独立审查原则
任何 PRD / 验收报告 / 工程文档不得由 AI 单方面标记 PASS。
AI 可在文档状态字段标注"待审查"，但不得标注"PASS / 放行 / 已通过"。

### R-2 三结论制度
所有审查必须由用户给出且只能给出三种结论之一：
- 放行：可进入下游
- 打回：需修正后重新审查
- 升级：超出当前权限，需更高层级决策

### R-3 审查记录强制写回
审查记录必须写入 docs/05审核与质量/审查记录.md，字段：
审查日期 / 文档名 / 审查人 / 结论 / 证据 / 备注

### R-4 违规失效规则
违反本规则的文档视为无效，不得作为下游依据。
AI 不得以"已自验通过"为由跳过用户审查。

### R-5 适用范围
本规则适用于所有 Skill 产出、PRD、验收报告、工程文档、复盘记录。
```

#### 3.3.4 P2.4 _index.md 扫描策略

**扫描范围**：`c:\Users\10919\Desktop\AWKN-Lab\记忆系统\03-sessions\`
- 顶层 session-XXX.md 文件
- `_auto-archive/` 子目录内 session 文件
- 日期分组：2026-06-17 至 2026-06-26（共 10 天）

**统计脚本（PowerShell）**：

```powershell
# scan-sessions.ps1 — _index.md 生成辅助
$sessionsDir = "c:\Users\10919\Desktop\AWKN-Lab\记忆系统\03-sessions"
$dates = @{}
Get-ChildItem -Path $sessionsDir -Filter "session-*.md" -Recurse | ForEach-Object {
    # 从文件名提取日期 session-YYYYMMDD-HHMMSS.md
    if ($_.Name -match "session-(\d{8})") {
        $dateKey = $matches[1]
        if (-not $dates.ContainsKey($dateKey)) {
            $dates[$dateKey] = 0
        }
        $dates[$dateKey]++
    }
}
$dates.GetEnumerator() | Sort-Object Name | Format-Table
```
