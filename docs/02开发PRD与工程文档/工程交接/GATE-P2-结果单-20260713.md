## 五、已知残余与风险

### R1: KlineShareCard 降级 (P3-01 范围)
- **现状**: V2 KlinePage 传 `bars={[]}` 给 V1 KlineShareCard，分享卡走空数据兜底
- **影响**: 分享图内容降级，不崩溃但内容不完整
- **计划**: P3-01 归并海报时统一为 V2 ViewModel 驱动

### R2: 节点问事 API 失败无 toast (低优先级)
- **现状**: askNode API 返回 null 时不跳转、不提示
- **影响**: 用户可能困惑为何点击无反应
- **计划**: 后续补充失败 toast

### R3: 免费用户节点数提示文案
- **现状**: 显示 "免费版仅显示前 N 个"
- **影响**: N 的计算基于实际返回的节点数，可能不准确
- **计划**: 后端 applyEntitlements 已做裁剪，前端文案可优化
