## 4. 关键架构决策记录

### 4.1 TypeScript rootDir 约束 — 本地副本策略

**问题**：api-server 的 tsconfig.json 继承自 awkn-life-backend/tsconfig.json，后者 `rootDir: "./"`，导致无法跨包 import shared-types。

**尝试**：
1. 改 rootDir 为 `rootDirs: ["./src", "../../shared-types"]` — 失败，父约束继承
2. 移除 rootDir 只保留 rootDirs — 失败

**最终方案**：在 `src/kline-tide/v2-contracts.ts` 创建本地副本，文件头标注同步策略："修改 shared-types/kline-v2.ts 时必须同步修改此文件"。

### 4.2 V1 弃用策略 — Interceptor 注入响应头

**方案**：保留 V1 端点只读，通过 NestJS Interceptor 注入 4 个弃用响应头：
- `X-Deprecation: kline-v1-deprecated`
- `X-Deprecation-Date: 2026-07-12`
- `X-Deprecation-Sunset: 2026-07-26`（14 天兼容期）
- `X-Upgrade-To: /api/v1/kline-v2`

### 4.3 功能开关分层

```
KLINE_V2_ENABLED               (主开关，控制 V2 全部端点)
KLINE_V2_PUBLIC_PREVIEW_ENABLED (公开分享预览)
KLINE_V2_NODE_ASK_ENABLED     (节点问事)
KLINE_V2_OUTCOME_ENABLED      (结果回写)
KLINE_SIMULATED_DATA_ALLOWED  (模拟数据，仅非生产)
```

### 4.4 黄金样例确定性验证策略

5 类边界案例 × 20 例：
1. 节气交接（立春/春分/夏至/立秋/冬至）
2. 大运交接（10/20/30/40/50/60 岁）
3. 流年交接（年初/年末/年中）
4. 出生时辰不确定（早子/晚子/夏令时）
5. 资料缺失（仅年/仅年月/无八字）

每例执行两次，验证 `factorsHash` 完全一致（C1+C2 双重确定性）。
