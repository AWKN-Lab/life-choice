#### 3.3.5 remind-archive.ps1 实现方案

**功能**：post-commit 触发，输出归档提醒文本（不阻塞 commit）

**算法**：
1. 读取上次归档索引更新时间（解析归档索引首行）
2. 计算距今天数
3. 若 ≥7 天，输出提醒文本"⚠️ 归档索引已 X 天未更新，请检查是否有新文档需要归档"
4. 若 <7 天，静默退出

**伪代码**：
```powershell
# remind-archive.ps1 — post-commit 归档提醒
$ErrorActionPreference = "SilentlyContinue"

$indexPath = "c:\Users\10919\Desktop\AWKN-Lab\人生决策宗师\docs\03开发过程稿\已完成执行计划归档索引.md"
if (!(Test-Path $indexPath)) { exit 0 }

# 读取首行日期
$firstLine = Get-Content $indexPath -TotalCount 3 | Select-String -Pattern '\d{4}-\d{2}-\d{2}'
if (!$firstLine) { exit 0 }

$lastArchiveDate = [datetime]::ParseExact($firstLine.Matches[0].Value, "yyyy-MM-dd", $null)
$daysSince = ((Get-Date) - $lastArchiveDate).Days

if ($daysSince -ge 7) {
    Write-Host "⚠️ 归档索引已 $daysSince 天未更新，请检查是否有新文档需要归档。"
    Write-Host "   归档索引路径：$indexPath"
    Write-Host "   上次归档时间：$($firstLine.Matches[0].Value)"
}

exit 0
```

**post-commit hook 集成**：

```bash
#!/bin/sh
# .husky/post-commit
powershell -ExecutionPolicy Bypass -File scripts/remind-archive.ps1
```
