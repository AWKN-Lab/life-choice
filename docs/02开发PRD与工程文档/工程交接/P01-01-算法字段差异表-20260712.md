# P01-01 算法字段差异表 — KlineGenerator vs KlineTideService

> 输出模式：严格可执行
> 创建时间：2026-07-12
> 用途：P1-02 KlineCalculationEngine 的字段合并依据；P1-07 咨询归口的接入依据
> 依据：以 `apps/api-server/src/consult/generators/kline.generator.ts` (584 行) 与 `apps/api-server/src/kline-tide/kline-tide.service.ts` (1487 行) 当前源码为准

---

## 一、两套算法的位置与角色

| 维度 | 路径 A：KlineGenerator (咨询链路) | 路径 B：KlineTideService (kline-tide 模块) |
|------|------------------------------------|-------------------------------------------|
| 文件路径 | `src/consult/generators/kline.generator.ts` | `src/kline-tide/kline-tide.service.ts` |
| 文件行数 | 584 | 1487 |
| 调用入口 | `consult.service.ts:2475 generateKlineContent` 内调用 `klineGenerator.generateKLineData` | `kline-tide.controller.ts` 路由 `/kline-tide/package` 等 |
| 触发场景 | 咨询结果页"趋势(kline)"模块 | K 线/潮汐独立页面 `KlinePage`/`TidePage` |
| 数据来源 | 实时计算，无 DB 持久化 | Prisma + SQLite；缺失时 `_seedKlineBars` 兜底 |
| 随机性 | 纯确定性（`Math.sin`/`Math.cos` 等三角函数推导，无 `Math.random`） | **`_seededRandom(seed)`** (line 1606) — `Math.sin`-based 伪随机 |
| 八字依赖 | 直接接 `BaziFullResult`（含 daYun/liuNian/wuxing/shenSha/shiShen） | 间接接 `BaZiProfile` 表（通过 `loadBaZiProfile`，仅取 yearGanZhi/dayGanZhi/shenWang/wuxing/shiShen/yongShen） |
| 输出形态 | `KlinePoint[]`（扁平单数组） | `TidePackage`（klineBars + stateSnapshots + phasePoints + tideJudgment） |
| 时间粒度 | `life` (年) / `decade` (10 年) / `monthly` (12 月) / `yearMonth` (0-100 岁 × 12 月) | 仅月度（klineMonths 默认 36，tideMonths 默认 12） |

### 3.2 路径 B 的因子（kline-tide.service.ts）

| 因子 | 来源 | 是否 A 对等 |
|------|------|------------|
| 7 维 OHLCV (career/wealth/health/relationship/growth/freedom/buffer) | `DIM_SEED` + `_applyBaziAdjustment`（仅用 yearGanZhi/dayGanZhi/shenWang/wuxing/shiShen/yongShen） | ⚠️ 部分用八字调整 seed 均值 |

**路径 B 是"伪命理数据生成器"：八字仅作为均值调整，主噪声靠 `_seededRandom`，时间序列靠 sin。**

## 五、保留/删除/改造清单（P1-02 + P1-03 + P1-07 依据）

### 5.1 保留（Retain）— V2 直接复用

| 来源 | 保留项 | 去向 |
|------|--------|------|
| 路径 A `KlineGenerator` 全部 15 因子 | `scoreDaYun`/`scoreGanZhi`/`scoreYongShen`/`scoreRelations`/`scoreShenSha`/`computeBaseChart`/`computeShiShenFactors`/`computeXingChongHeHai`/`computeRiskPenalty` | → 移入 `KlineCalculationEngine.calculate(baziResult, age, year, month?)` |
| 路径 A `weightedScore` 权重公式 | 0.20/0.18/0.10/0.05/0.08/0.12/0.02×8/0.05/-penalty | → V2 默认权重，由 factor-registry 覆盖 |
| 路径 B `KlineDataSource` 类型 | 'real'\|'simulated'\|'llm_inferred'\|'fallback' | → V2 全链路 source 标识 |
| 路径 B `KlineDimension` 类型 | career/wealth/health/relationship/growth/freedom/buffer | → V2 维度枚举 |
| 路径 B `CurrentStage` 6 态 | breakthrough/attack/buildup/pullback/repair/wait | → V2 阶段判定（与路径 A 的"上升/调整/蓄势/转折"做映射） |
| 路径 B `ParsedKlineBar.source` 字段 | P0 已加 | → V2 持久化字段 |
| 路径 B `_seededRandom` | 确定性伪随机 | → 保留方法，但 V2 链路拒绝调用 |

### 5.2 删除（Delete）— V2 链路不调用

| 来源 | 删除项 | 理由 |
|------|--------|------|
| 路径 B `_seedKlineBars` | V2 链路不写模拟数据 | 由 `KlineCalculationEngine` 实时算 |
| 路径 B `_seedStateSnapshots` | 同上 | 由 `KlineCalculationEngine` 实时算 |
| 路径 B `_applyBaziAdjustment` | 仅用部分八字字段调整 seed 均值，不真实 | V2 用完整 `BaziFullResult` 直接算 |
| 路径 B `DIM_SEED` 常量 | 7 维均值/振幅/趋势表 | V2 不需要 |
| 路径 B `STATE_DIMS` 12 维向量 | 与八字无关 | V2 不需要（除非 P4 决定保留状态快照作为"叠加层"） |
| 路径 A `KlineViewMode = 'monthly'` | 仅 12 个月滚动 | V2 统一用 `yearMonth` 替代 |
| 路径 A `KlinePoint.monthName` | 中文月名 | V2 用 ISO `month` 数字 |
| 路径 A `KlinePoint.ganZhi`/`daYun`/`liuNian` | 命理字段混入数据点 | V2 拆分到 `KlineNode.ganZhi`（节点级），不出现在每点 |

### 5.3 改造（Rewire）— P1-02/P1-06/P1-07 接线

| 来源 | 改造项 | 去向 |
|------|--------|------|
| 路径 A `KlineGenerator.generateKLineData` | 改为薄封装，调用 `KlineCalculationEngine.calculate` | 输出仍为 `KlinePoint[]`，向后兼容 consult.service |
| 路径 A `KlinePoint.score` | 拆为 `KlineBar.close`（数据层）+ `KlineOutcome.score`（结果层） | V2 三表分离 |
| 路径 B `TidePackage.klineBars` | V2 链路改为 `KlineSnapshot.bars` | 数据结构升级 |
| 路径 B `TidePackage.stateSnapshots` | V2 链路改为 `KlineNode.outcomes` | 由 6 态简化为 5 态 |
| 路径 B `CurrentStageResult` | V2 改为 `KlineNode.askResult` | 节点级询问 |
| 路径 B `KlineStageInput` | V2 改为 `KlineNodeAskInput` | 节点级询问入参 |
