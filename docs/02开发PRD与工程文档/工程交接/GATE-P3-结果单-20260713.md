## 五、已知残余与风险

### R1: KlineComparePage 分享功能降级 (低优先级)
- **现状**: V1 对比页分享按钮降级为引导链接到 /kline
- **影响**: V1 对比页用户无法直接生成分享卡，需跳转 /kline
- **计划**: V2 全量切换后 KlineComparePage 将废弃，无需单独修

### R2: V1-B KLineShareCard 保留为兼容 (低优先级)
- **现状**: components/KLineShareCard.tsx (V1-B) 仍存在，待 V2 全量切换后移除
- **影响**: 代码冗余，但无运行时影响
- **计划**: P4 阶段或 V2 全量切换后统一清理

### R3: 公开分享 token 安全性 (中优先级)
- **现状**: GET /share/:token 中 token 直接使用 snapshotId，未做签名
- **影响**: 知道 snapshotId 即可访问他人分享预览（仅脱敏数据）
- **计划**: 后续迭代改为签名 token (JWT 或 HMAC)

### R4: 跨用户后台查看 (P4 范围)
- **现状**: KlineV2AdminSection 调用 GET /kline-v2/snapshots 仅返回当前用户 snapshot
- **影响**: 管理员无法查看所有用户的 V2 资产
- **计划**: P4 阶段扩展后端 admin 端点支持跨用户查看

### R5: 回访提醒逻辑基于 monthLabel 字符串比较 (低优先级)
- **现状**: KlineReminderBanner 用 `node.monthLabel < currentMonthLabel` 字符串比较
- **影响**: 依赖 monthLabel 格式严格一致 (YYYY-MM)
- **计划**: 后续可改为 ISO 日期或数值化比较
