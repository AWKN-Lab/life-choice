## 一、调度总原则

张半山收到用户问题后的第一步不是回应，是判断意图类型。根据意图类型决定主调 Agent、佐调 Agent，以及是否需要反问用户确认。

调度过程分三步：

1. **关键词匹配** → 确定问题类型
2. **反问确认** → 一句话确认用户真实意图（不是表面问题）
3. **Agent 调度** → 主调 + 佐调 + 调度理由

## 二、问题类型 → Agent 映射表

### 类型 1：现在该不该动

| 维度 | 内容 |
|------|------|
| **关键词** | 跳槽、辞职、出国、要不要走、离职、换工作、换个城市 |
| **张半山第一问** | 「你是想动还是想等？」 |
| **主调 Agent** | **六壬** |
| **佐调 Agent** | **奇门** |
| **调度理由** | 六壬最擅长时机判断——问「该不该动」本质是问时机对不对。奇门作为佐调，提供空间维度——如果动了，哪个方向更有利 |
| **不调用的 Agent** | 八字（格局问题，非时机问题）；六爻（一事一问但不如六壬擅长时机窗口） |

### 类型 2：两个方向选哪个

| 维度 | 内容 |
|------|------|
| **关键词** | 选A还是选B、哪个更、抉择、两条路、两个方向、纠结、不知道选哪个 |
| **张半山第一问** | 「两个方向你最怕哪个结果？」 |
| **主调 Agent** | **奇门** |
| **佐调 Agent** | **六壬** |
| **调度理由** | 奇门擅长空间/方向抉择——问「选哪个」是空间问题。六壬作为佐调，看两个方向各自的时间窗口哪个更有利 |
| **不调用的 Agent** | 八字（不擅长空间维度）；紫微（性格匹配不解决方向抉择） |

### 类型 3：考研/创业/重大人生转折

| 维度 | 内容 |
|------|------|
| **关键词** | 考研、创业、转行、考公、考编、人生转折、要不要搏一把 |
| **张半山第一问** | 「你现在最担心的是什么？」 |
| **主调 Agent** | **八字/子平** |
| **佐调 Agent** | **紫微** |
| **调度理由** | 八字看格局——考研/创业这类人生转折本质是格局问题：你的命盘是否适合走这条路。紫微看性格匹配——你的性格和这条路是否匹配 |
| **不调用的 Agent** | 六壬（时机不是核心，格局才是）；梅花（直觉捕不准格局） |

### 类型 4：感情要不要继续

| 维度 | 内容 |
|------|------|
| **关键词** | 分手、离婚、感情、关系、要不要继续、该不该分、他/她还爱不爱 |
| **张半山第一问** | 「你是累了还是寒了？——累了是消耗，寒了是关系本身的温度变了，这是两件事。」 |
| **主调 Agent** | **梅花** |
| **佐调 Agent** | **紫微** |
| **调度理由** | 梅花捕第一直觉——感情问题最怕分析过度，先捕用户的真实感受再给判断。紫微看关系结构——两个人的性格配合、宫位互动 |
| **⚠️ 当前状态** | 梅花 Agent 代码层面**尚未实现**，MVP 阶段用**六爻**替代梅花。决策树后续更新 |
| **不调用的 Agent** | 奇门（感情不是空间方向问题）；八字（不给感情贴「命格不配」的标签） |

### 类型 5：整体命运如何

| 维度 | 内容 |
|------|------|
| **关键词** | 命运、命盘、命中注定、整体运势、这辈子、格局、命格 |
| **张半山第一问** | 「你想看哪一段？最近一年、未来三年、还是整体格局？」 |
| **主调 Agent** | **八字/子平** |
| **佐调 Agent** | **六壬** |
| **调度理由** | 八字看长线——整体命运是格局问题，看大运走势。六壬看节点——在长线中标注哪些时间点是关键窗口 |
| **不调用的 Agent** | 六爻（一事一问不适合整体命运）；梅花（直觉捕不准长期格局） |

### 类型 6：一件事成不成

| 维度 | 内容 |
|------|------|
| **关键词** | 能不能、成不成、行不行、成功概率、有没有戏、靠谱吗 |
| **张半山第一问** | 「这事是你想做的还是该做的？——想知道结果和想知道应该不应该，调度策略不同。」 |
| **主调 Agent** | **六爻** |
| **佐调 Agent** | **奇门** |
| **调度理由** | 六爻擅长一事一问——「这件事成不成」是六爻的核心场景。奇门作为佐调，看这事的外围环境是否有利 |
| **不调用的 Agent** | 八字（一事一问不需要整体格局）；紫微（性格匹配不解决结果预测） |

### 类型 7：想知道时机

| 维度 | 内容 |
|------|------|
| **关键词** | 什么时候、时机、该不该现在、等还是不等、还要多久、还要等 |
| **张半山第一问** | 「你现在卡在哪里？——你说时机，那现在让你动不了的核心原因是什么？」 |
| **主调 Agent** | **六壬** |
| **佐调 Agent** | **梅花** |
| **调度理由** | 六壬看时机窗口——精确到月/季的时间窗口判断。梅花捕第一念——用户直觉上认为什么时候可以动 |
| **⚠️ 当前状态** | 梅花 Agent 代码未实现，MVP 阶段佐调降级为「无佐调，仅六壬」。后续梅花实现后恢复 |
| **不调用的 Agent** | 八字（不擅长精确时机窗口）；奇门（时机问题不是空间问题） |

### 类型 8：重大决策（全系统并行）

| 维度 | 内容 |
|------|------|
| **触发条件** | 满足以下**任一**条件：<br>① 用户同时问了两个以上维度的问题（如「我想跳槽但家里不同意，怎么选」→ 涉及时机+感情+方向三个维度）<br>② 用户语言中出现「人生大事」「不知道怎么选」「怎么想都想不明白」<br>③ 用户反复追问同一个问题超过 3 轮 |
| **张半山行为** | 先确认用户状态：「你现在这个情况，不止一个维度在拉扯你。我需要同时从几个角度帮你看——会比平时慢一点，但会更全面。你愿意等吗？」 |
| **主调 Agent** | **全系统并行**：六壬 + 奇门 + 八字/子平 + 紫微 + 六爻（不含未实现的梅花） |
| **佐调 Agent** | 无（全系统均为主调） |
| **调度理由** | 重大决策涉及多个维度交叉，单一 Agent 无法覆盖全部视角。全系统并行后由张半山交叉分析层统一仲裁 |
| **⚠️ MVP 阶段降级** | 全系统并行 = 5-6 次 LLM 调用，成本和延迟双高。MVP 阶段限制为**最多 2 Agent 并行**（1 主 + 1 佐），全系统并行延后到 v2 |

## 三、调度决策流程图

```
用户输入
  │
  ├─ 关键词匹配 → 命中类型 1-7？
  │     │
  │     ├─ 是 → 反问确认（张半山第一问）
  │     │         │
  │     │         ├─ 用户意图明确 → 调度主调 + 佐调
  │     │         └─ 用户意图模糊 → 追加背景问题 → 重新匹配
  │     │
  │     └─ 否 → 检查是否触发「重大决策」条件
  │               │
  │               ├─ 是 → 全系统并行（MVP 降级为 2 Agent）
  │               └─ 否 → 默认识别为「一件事成不成」类型 6
  │
  └─ 调度完成 → 执行 Agent 调用 → 张半山交叉分析
```

## 四、调度决策树优先级规则

当用户输入匹配多个类型时，按以下优先级：

| 优先级 | 类型 | 理由 |
|--------|------|------|
| 1 | 类型 8（重大决策） | 多维交叉问题需要全系统判断，单一类型偏差风险高 |
| 2 | 类型 6（一件事成不成） | 一事项问最具体，最容易判断，放在靠前 |
| 3 | 类型 4（感情） | 感情问题情绪包裹，需要优先识别 |
| 4 | 类型 3（人生转折） | 格局问题优先级高于时机和方向 |
| 5 | 类型 1（该不该动） | 时机问题 |
| 6 | 类型 2（选方向） | 方向问题 |
| 7 | 类型 7（时机） | 时机细节问题 |
| 8 | 类型 5（整体命运） | 最泛的问题，最后匹配 |

---

## 五、MVP 降级规则

考虑到梅花 Agent 未实现、全系统并行延迟过高，MVP 阶段执行以下降级：

| 原调度 | MVP 降级 |
|--------|---------|
| 梅花（主）+ 紫微（佐） | **六爻**（主）+ 紫微（佐） |
| 全系统并行（5-6 Agent） | **最多 2 Agent 并行**（选与问题最相关的两个） |
| 六壬（主）+ 梅花（佐） | **六壬**（主）+ 无佐调 |
| 其他组合 | 不变 |

## 六、Agent 能力边界速查

| Agent | 擅长 | 不擅长 | 调度场景 |
|-------|------|--------|---------|
| **六壬** | 时机窗口（月/季精度）、关键节点 | 空间方向、整体格局 | 该不该动、时机 |
| **奇门** | 空间/方向抉择、外围环境 | 格局、一事一问 | 选方向 |
| **八字/子平** | 格局走势（年精度）、长线趋势 | 精确时机、一事一问 | 人生转折、整体命运 |
| **紫微** | 性格匹配、关系结构、宫位互动 | 时机、方向 | 佐调（配合八字/梅花） |
| **六爻** | 一事一问、结果预测 | 格局、时机 | 成不成 |
| **梅花** | 第一直觉、感情方向 | 精确预测、格局 | 感情、直觉判断 |

## 七、验证方法

用 5 个不同类型的问题逐一检查：

| # | 测试输入 | 预期调度 | 预期第一问 |
|---|---------|---------|-----------|
| 1 | 「我想跳槽，但不确定要不要走」 | 六壬（主）+ 奇门（佐） | 「你是想动还是想等？」 |
| 2 | 「考研还是工作，两个都不知道怎么选」 | 八字（主）+ 紫微（佐） | 「你现在最担心的是什么？」 |
| 3 | 「和男朋友在一起三年，累了」 | 六爻（主·MVP降级）+ 紫微（佐） | 「你是累了还是寒了？」 |
| 4 | 「这个项目能不能做成」 | 六爻（主）+ 奇门（佐） | 「这事是你想做的还是该做的？」 |
| 5 | 「什么时候是个头啊，一直等一个机会」 | 六壬（主）+ 无佐调（MVP降级） | 「你现在卡在哪里？」 |
