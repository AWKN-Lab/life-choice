## 2. 新增接口

### 2.1 取名历史查询

| 属性 | 值 |
|------|-----|
| **方法** | GET |
| **路径** | `/api/v1/consult/naming/history` |
| **鉴权** | JWT（必须登录） |
| **说明** | 查询当前用户的取名历史记录 |

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 20 |

**Response 200**：
```json
{
  "records": [
    {
      "id": "uuid",
      "consultRecordId": "uuid",
      "names": [
        { "name": "张明远", "score": 95, "analysis": "天格火生人格土，大吉" }
      ],
      "wuge": { "tian": "火", "ren": "土", "di": "金", "wai": "水", "zong": "木" },
      "sancai": { "tian": "火", "ren": "木", "di": "土" },
      "createdAt": "2026-06-16T00:00:00Z"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}
```

**Error 401**：未登录
**Error 500**：服务异常

### 2.2 K线名人对比

| 属性 | 值 |
|------|-----|
| **方法** | GET |
| **路径** | `/api/v1/kline/compare` |
| **鉴权** | JWT |
| **说明** | 对比用户 K 线与预置名人 K 线 |

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| celebrityId | string | 是 | 名人 ID（预置列表） |
| birthDate | string | 是 | 用户出生日期 YYYY-MM-DD |
| gender | string | 是 | male / female |

**Response 200**：
```json
{
  "userKline": { "bars": [...], "snapshots": [...] },
  "celebrityKline": { "bars": [...], "snapshots": [...] },
  "comparison": {
    "similarity": 0.72,
    "keyDifferences": ["事业线峰值晚 5 年", "财运波动更剧烈"]
  }
}
```

### 2.3 限免记录查询

| 属性 | 值 |
|------|-----|
| **方法** | GET |
| **路径** | `/api/v1/membership/free-trial` |
| **鉴权** | JWT |
| **说明** | 查询当前用户是否已使用限免机会 |

**Response 200**：
```json
{
  "used": true,
  "usedAt": "2026-06-16T00:00:00Z",
  "featureType": "naming_result"
}
```

---

### 2.4 限免记录写入

| 属性 | 值 |
|------|-----|
| **方法** | POST |
| **路径** | `/api/v1/membership/free-trial/record` |
| **鉴权** | JWT |
| **说明** | 记录用户使用了一次限免 |

**Body**：
```json
{
  "featureType": "naming_result"
}
```

**Response 200**：
```json
{
  "success": true,
  "remainingFreeTrials": 0
}
```

**Error 409**：已使用过限免（幂等性检查）

## 3. 变更接口

### 3.1 取名咨询（扩展）

| 属性 | 值 |
|------|-----|
| **方法** | POST |
| **路径** | `/api/v1/consult/naming` |
| **变更** | 响应后额外调用 `saveNamingResult()` 将结果写入 NamingResult 表 |

**行为变更**：原接口只写 ConsultRecord，现在同时写 NamingResult。接口签名不变，对前端透明。

---

### 3.2 增长模块 - 邀请记录（扩展）

| 属性 | 值 |
|------|-----|
| **方法** | POST |
| **路径** | `/api/v1/growth/referral/record` |
| **变更** | 新增 `level` 字段支持 3 级返利 |

**Body 扩展**：
```json
{
  "inviteCode": "xxx",
  "source": "poster",
  "medium": "wechat",
  "campaign": "kline_v1",
  "level": 2
}
```

---

### 3.3 埋点事件（扩展）

| 属性 | 值 |
|------|-----|
| **方法** | POST |
| **路径** | `/api/v1/analytics/event` |
| **变更** | 新增 `landing_view` 和 `qr_scan_back` 两种事件类型 |

**landing_view payload**：
```json
{
  "event": "landing_view",
  "properties": {
    "utm_source": "poster",
    "utm_medium": "wechat",
    "utm_campaign": "kline_v1",
    "pageName": "landing"
  }
}
```

**qr_scan_back payload**：
```json
{
  "event": "qr_scan_back",
  "properties": {
    "source": "kline_poster",
    "inviteCode": "xxx"
  }
}
```

## 4. 错误码

| 错误码 | 含义 | 触发场景 |
|--------|------|----------|
| 401 | 未登录 | 访问需鉴权接口但未携带 JWT |
| 403 | 无权限 | 非会员访问付费内容 |
| 409 | 冲突 | 重复使用限免机会 |
| 404 | 不存在 | 名人 ID 不存在 |
| 500 | 服务异常 | 后端内部错误 |
