## 12. 当前接口风险

1. 知识向量与混合检索约 10–15 秒，可能拖慢主咨询链。
2. `/kline-tide/seed` 是写入接口，需要生产级访问控制。
3. 生产数据库缺少 `ConsultDialogueTurn` 与 `MemoryEmbedding`，相关代码路径需防止直接写入缺失表。
4. API 文档尚未由 OpenAPI 自动生成，当前基线来自真实启动路由与代码扫描。
5. 生产工作区未收口到单一 commit，接口变更无法仅靠 Git tag 精确追溯。
