## 2. Phase 0 验收用例

### P0-01｜QR 生成功能

| 项 | 内容 |
|----|------|
| **前置** | `qrcode` 依赖已安装 |
| **操作** | 调用 `generateQR('https://awkn.cn/life/?utm_source=test', 200)` |
| **预期** | 返回 base64 PNG 字符串，长度 > 1000 字符 |

| **预期** | QR 可识别，URL 包含 `utm_source=kline` |

### P0-03｜通用海报含真 QR

| 项 | 内容 |
|----|------|
| **前置** | Phase 0 完成，PosterGenerator 已替换 |

| **预期** | 4 种海报 QR 都可识别，URL 含对应 utm_source |

### P0-04｜UTM 解析

| 项 | 内容 |
|----|------|

## 6. 自动化验证脚本规范

所有 `verify/*.mjs` 脚本遵循统一规范：

```javascript
import { chromium } from 'playwright';

const BASE_URL = process.env.BASE_URL || 'http://localhost:5173';

async function main() {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  const failures = [];

  // ... 测试逻辑 ...

  await browser.close();

  if (failures.length > 0) {
    console.error('FAIL:', failures);
    process.exit(1);
  }
  console.log('PASS');
}

main().catch(e => { console.error(e); process.exit(1); });
```

**脚本清单**：

| 脚本 | 验证目标 | Phase |
|------|----------|-------|
| verify-qr-codes.mjs | 4 种海报 + K线海报的 QR 真伪 + URL 含 UTM | P0 |
| verify-utm-flow.mjs | UTM 从 URL → store → 后端 PageVisit 全链路 | P0 |
| verify-naming-db.mjs | 取名完成后 NamingResult 表落库 + 前端可查 | P1 |
| verify-landing-page.mjs | /landing 页面 CTA 渲染 + UTM 透传 | P1 |
| verify-paywall.mjs | 倒计时 + 限免 1 次逻辑 | P2 |
| verify-referral-chain.mjs | 3 级邀请返利数据链路 | P2 |
