## 4. 最低接口用例

```bash
curl -sf http://127.0.0.1:30000/api/v1/health
curl -sf http://127.0.0.1:30000/api/v1/health/db
curl -sf http://127.0.0.1:30000/api/v1/health/ready
curl -sf http://127.0.0.1:8701/health
curl -sf http://127.0.0.1:8701/health-v2
```

### 4.2 知识检索

```bash
curl -sS -X POST http://127.0.0.1:8701/retrieve \
  -H 'Content-Type: application/json' \
  -d '{"routeType":"ziping","question":"日主身弱","limit":3}'

curl -sS -X POST http://127.0.0.1:8701/embed_search \
  -H 'Content-Type: application/json' \
  -d '{"question":"紫微斗数夫妻宫怎么看","systemType":"ziwei","limit":3}'

curl -sS -X POST http://127.0.0.1:8701/hybrid_search \
  -H 'Content-Type: application/json' \
  -d '{"routeType":"ziping","question":"日主身弱","limit":5}'
```

```bash
curl -k -I https://awkn.cn/life/
curl -k -I https://awkn.cn/life/question
curl -k -I https://awkn.cn/life/kline
```

## 5. 关键业务链测试矩阵

| 链路 | 正常流 | 边界/异常流 |
|---|---|---|
| 注册 | 邮箱/手机号成功注册 | 重复账号、弱密码、非法字段 |
| 登录 | 获取有效 Token | 错误密码、过期 Token |
| 问事 | 完整资料提交并产出结果 | 缺资料、LLM 超时、知识服务超时 |
| 澄清 | need_clarify 后补充成功 | 超过轮次、空回复、对话过期 |
| 结果 | recordId 可读取 | 无权限、记录不存在 |
| K线 | 有档案用户读取 | 无档案、缺时辰、seed 来源 |
| 会员 | 读取余额与权益 | 无会员、余额不足 |
| 支付 | 测试环境创建和回调 | 重复回调、签名错误、退款 |
| 后台 | 管理员读取 | 普通用户 403 |
| 知识 | 正确体系命中 | 跨体系污染、空结果、超时 |
