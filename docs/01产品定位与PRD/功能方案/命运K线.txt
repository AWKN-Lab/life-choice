**4. OHLCV 映射规则**
命运K线的 OHLCV 定义：

```text
open：周期开始势能
high：本周期机会上限
low：本周期风险下探
close：综合落点
score：默认等于 close
volume：事件激活度
```

基础公式：

```ts
close =
  baseChart * 0.20
  + daYun * 0.25
  + yearly * 0.25
  + aspect * 0.20
  + knowledge * 0.10
  - riskPenalty;
```

边界：

```ts
score = clamp(close, 5, 95)
high = clamp(close + opportunityScore * 0.35 + volume * 0.12, score, 100)
low = clamp(close - riskPenalty * 0.7 - volume * 0.08, 0, score)
open = previousClose * 0.65 + currentBase * 0.35
```

`volume` 计算：

```ts
volume =
  conflictCount * 10
  + combinationCount * 6
  + shenShaHitCount * 5
  + knowledgeHitCount * 8
  + daYunChangeBonus
```

解释：

- `volume` 不是成交量，是“事件激活度”。
- 分数高但 volume 低：顺，但未必有大事。
- 分数中等但 volume 高：容易出现变化、机会或冲突。
- `high` 高、`close` 低：机会看得到，但落地不稳。

**10. 信号规则**
首批信号：

```text
启势金叉：
短期均线向上，当前 close > 前一年 close，volume 增强。

贵人放量：
天乙、文昌、将星等正向因子命中，volume 明显抬升。

财星突破：
财运线 close 高于近五年均值，并命中财星/食伤生财。

关系异动：
情感线 volume 抬升，命中桃花/红鸾/夫妻宫冲合。

空亡回撤：
机会分高，但空亡/落空因子强，high 高 close 低。

冲刑破位：
冲刑害破集中，low 明显下探，riskPenalty 高。

用神回归：
用神相关五行/十神在大运或流年中重新增强。
```

信号输出：

```ts
{
  id: 'wealth_breakout',
  label: '财星突破',
  level: 'positive',
  description: '财运线突破近期均值，适合关注变现与资源转化。',
  evidenceTags: ['食伤生财', '财星透出']
}
```

**11. 后端接口策略**
V2 首选：不新增接口。

沿用：

```http

```

响应兼容：

```ts
{
  module_content: {
    chartData: KLinePoint[],
    yearData: KLinePoint[],
    destinyKline?: DestinyKlineBundle
  }
}
```

前端处理优先级：

```ts
const bundle =
  moduleContent.destinyKline
  ?? deriveDestinyKline(result.calc_result, moduleContent.chartData)
```
