## 写入规则

1. 产品定位、用户任务、模块范围、指标和验收写入本目录。
2. 工程实现、接口、数据库、测试和部署写入 `docs/02开发PRD与工程文档/`。
3. 执行计划和过程记录写入 `docs/03开发过程稿/`。
4. 复盘和验收写入 `docs/04复盘总结/`、`docs/05审核与质量/`。
5. `docs/02产品需求 (PRD)/` 已冻结，停止新增文档。
