# PRD：知识库数据化与三法融合

> 版本：v0.1
> 日期：2026-05-28
> 来源：从 八字六壬典籍数据化与向量检索落地计划.md、三法融合与知识库数据化计划.md 中提取的未完成任务

## 一、产品定位
将命理典籍数据化，构建向量检索系统，实现八字、紫微、六壬三法融合的智能推理。

## 二、MVP功能清单

### P0（必须完成）
1. **八字典籍数据化**：将核心八字典籍转为结构化JSON
2. **向量检索基础设施**：部署向量数据库，建立embedding管线
3. **八字知识库检索**：实现基于向量的八字知识检索

### P1（应该完成）
4. **紫微斗数典籍数据化**：核心紫微典籍结构化
5. **六壬典籍数据化**：核心六壬典籍结构化
6. **三法融合推理Prompt**：综合三法知识的推理策略

### P2（可以延后）
7. **知识库版本管理**：典籍更新的版本控制
8. **知识库质量评估**：检索准确率评估框架
9. **用户自定义知识注入**：允许用户补充个人命理笔记

## 三、不做清单
1. 不做全量典籍扫描（先做核心典籍）
2. 不做知识图谱可视化
3. 不做自动典籍翻译
4. 不做社区贡献系统
5. 不做知识付费

## 四、验收用例
1. 八字核心典籍 ≥ 3本完成数据化
2. 向量检索召回率 ≥ 80%
3. 检索响应时间 ≤ 500ms
4. 三法融合推理覆盖 ≥ 5个典型场景
5. 数据化典籍可被Agent正确引用

## 五、约束
- 典籍来源需确认版权合规
- 向量数据库选型需与现有技术栈兼容
- 数据化过程需保持命理准确性
