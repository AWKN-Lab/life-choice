## 六、关键发现汇总

### 6.1 PR-C 未部署证据链（4 重确认）

1. main.py 无 `_EMBED_VERSION` 变量
2. PM2 env 无 `KNOWLEDGE_EMBED_VERSION`
3. health-v2 响应无 `embed_version` 字段
4. v3 制品（embeddings_v3.npy, _embed_meta_v3.json, BGE 模型）不存在

### 6.2 数据版本差（已量化）

| 层 | 数量 | 含义 |
|---|---:|---|
| 关键词语料池 | 329577 | load_all() 加载的全量 passage |
| 向量索引 | 137337 | 已生成 TF-IDF embedding 的 passage |
| 缺口 | **192240** | 有关键词但无向量表示 |

**正确风险描述**：
> 192240 条语料（占 58.3%）缺少语义向量召回，只能依赖关键词召回；同义表达、隐含语义、跨术语查询的召回质量可能显著下降。

**不成立结论**（已在二次复核中纠正）：
- ❌ "58.3% 知识用户搜不到" — hybrid_search 有 /retrieve 关键词回退
- ❌ "两套完全不同实现" — 生产是同一架构旧版本

### 6.3 生产性能问题（新发现，P0 范围外）

| 端点 | 延迟 | 状态 |
|---|---:|---|
| /health | 0.002s | ✅ 健康 |
| /health-v2 | 0.004s | ✅ 向量库已加载 |
| /hybrid_search (冷) | 8.278s | ⚠️ mmap 首次加载 |
| /hybrid_search (热) | 3.5-4s | ⚠️ **慢于预期** |

**待 P2 评估**：
- 3.5-4s 是否 TF-IDF query encode 耗时（fit + transform）
- mmap 读取是否 IO 瓶颈
- _emb_norms 是否已预计算（代码显示应该已预计算）
- 是否可改为全量内存加载（KNOWLEDGE_USE_MMAP=0）
