## 10. 问题清单

### P0-001: 生产 src 不完整（47 个模块缺失）
- **级别**: P0
- **现象**: `npm run build` 报 47 个 TS2307 Cannot find module 错误
- **证据**: zhangbanshan-scheduler.service.ts 引用 prompt-layers/emotion-state/scenario-rules-loader 等，但这些文件在 src 中不存在
- **根因**: 生产 Git commit 4bbcd7c 是旧版本，src/consult/ 目录结构不完整。历史部署只上传 dist，从未同步 src
- **影响**: 生产无法独立 build，任何需要重新 build 的部署都会失败
- **建议处理**: 后续部署统一用"本地 build dist → 上传"方式，不依赖服务器 build
- **是否阻塞上线**: 否（已用本地 dist 部署成功）

### P0-002: 生产 Git 仓库与本地完全分叉
- **级别**: P0
- **现象**: 生产 commit 4bbcd7c (master) 本地不存在；本地 commit 4b27314f (main) 生产不存在
- **证据**: 生产无 remote，`git log --all` 无 4bbcd7c 匹配
- **根因**: 生产仓库是孤立仓库，从未与远程同步
- **影响**: 无法用 git pull 同步代码，部署只能靠文件上传
- **建议处理**: 在生产仓库添加 remote，建立同步机制；或统一用 dist 上传部署
- **是否阻塞上线**: 否（已用 dist 上传绕过）

### P1-001: PM2 重启次数 338 次
- **级别**: P1
- **现象**: PM2 重启 338 次（历史 337 + 本次 1）
- **证据**: `pm2 describe` 显示 restarts: 338
- **根因**: 历史 preflight 失败（meihua-agent/prompts 缺失）导致循环重启
- **影响**: 当前已稳定（uptime 持续增长），但历史不稳定
- **建议处理**: `pm2 reset awkn-life-backend` 清零计数器（不影响运行）
- **是否阻塞上线**: 否

### P1-002: 服务器无 package-lock.json
- **级别**: P1
- **现象**: `ls package-lock.json` 不存在
- **证据**: 独立验证环境用 `npm install` 而非 `npm ci`
- **根因**: 生产从未提交 lock 文件
- **影响**: 依赖版本可能漂移，无法精确复现
- **建议处理**: 本地生成 lock 文件并提交到生产
- **是否阻塞上线**: 否

### P2-001: 519 个未提交修改
- **级别**: P2
- **现象**: `git diff HEAD --stat` 显示 519 文件变更
- **证据**: 主要是 _archive 删除 + knowledge/processed 数据变化
- **根因**: _archive 未加入 .gitignore；knowledge 数据未隔离
- **影响**: 不影响运行，但干扰 git status
- **建议处理**: 服务器仓库添加 .gitignore 排除 _archive 和 knowledge/processed
- **是否阻塞上线**: 否
