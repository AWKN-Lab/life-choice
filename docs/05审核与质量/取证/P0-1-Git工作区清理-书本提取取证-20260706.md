## 4. 模型降级说明

### 4.1 当前状态

- **原计划模型**: BGE（推测 `BAAI/bge-large-zh-v1.5`）
- **实际使用模型**: TF-IDF char-bigram-v1（plan_b_used=true）
- **降级原因**: `huggingface.co` 网络不可达（5 秒超时）
- **降级日期**: 2026-06-18（_embed_meta.json generated_at）
- **耗时**: 194.4 秒（329577 passages，1695 passages/sec）

### 4.2 影响评估

- TF-IDF char-bigram 是字符级 n-gram 统计，无语义理解
- BGE 是 1024 维语义向量，能理解同义/上下位
- 降级期间 RAG 检索质量受限（precision@10=0.917 已通过 G6-0 评估，但召回质量有上限）
- 评估报告：`knowledge/processed/g6_0_evaluation.jsonl` 11/12 通过，1 项 borderline

## 8. 附录：取证方法说明

### 8.1 取证工具

- `git show <sha> --stat`：查 commit 内容
- `git log --oneline | Select-String`：关键词过滤
- `Get-Content *.jsonl | Measure-Object -Line`：行数计数
- `Get-Content *.jsonl | ConvertFrom-Json | Group-Object <field>`：字段分组
- `Test-Path`：文件存在性验证
- `Get-ChildItem -Recurse -Filter *.md | Measure-Object`：递归文件计数
- `Invoke-WebRequest -TimeoutSec 5`：网络可达性验证

### 8.2 取证原则

1. **git 取证优先**：所有声称以 git commit + 实际文件内容为准
2. **数学闭环验证**：每条数据必须能被另一个数据源交叉验证
3. **缺失项显式标注**：missing 不掩盖，标为缺口并给出恢复路径
4. **降级显式记录**：plan_b_used=true 必须在 _embed_meta.json 中明示
