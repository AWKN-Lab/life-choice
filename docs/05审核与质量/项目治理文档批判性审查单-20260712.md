### H6｜批次标准模板"回滚点 commit hash 必填，未提交则禁止开始批次"措辞有歧义

**假设**：交接包 §9 和技术参考 §4.1 的批次标准模板都写"回滚点 commit hash：____（必填，未提交则禁止开始批次）"，但阶段 0 是第一个批次，开始时还没有任何本批次提交，"未提交"指什么？接手者可能误解为"批次提交前不能开始批次"，造成逻辑死循环。

**证伪**：
- 交接包 §3.1 验收第 9 项："记录当前 HEAD commit hash 作为阶段 0 回滚点"
- 实际意图：回滚点 = 批次开始前的工作区 HEAD hash（不是批次提交后的 hash）
- "未提交"应理解为"未记录"，即未在批次单中记录回滚点 hash
- 但字面意思确实是"未提交"，容易误读

**严重度**：P1（措辞歧义可能导致阶段 0 执行卡壳或回滚点记录遗漏）

**修复建议**：交接包 §9 和技术参考 §4.1 的模板字段说明改为：
```
回滚点 commit hash：____（必填，= 批次开始前的工作区 HEAD hash；未记录则禁止开始批次）
```
