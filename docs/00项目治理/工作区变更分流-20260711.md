## 五、日常命令

```bash
# 查看真实内容变更并排除 stat-only 噪声
npm run audit:changes

# 查看提交批次地图
npm run audit:batches

# 展开每个工作流的文件
powershell -NoProfile -ExecutionPolicy Bypass \
  -File scripts/maintenance/workspace-change-map.ps1 -VerboseFiles

# 核验历史文档迁移
npm run audit:moves

# 核验可安全清理的杂物
npm run audit:junk

# 查看目录风险
npm run audit:workspace

# 预演根目录整理
npm run organize:workspace
```

## 六、进入物理迁移的条件

1. 有效内容变更降到 25 项以内。
2. 删除项为 0，或全部通过迁移内容核验。
3. 暂存区只包含当前批次文件。
4. 产品代码测试和类型检查通过。
5. 当前 HEAD 和回滚点已经记录。
6. 整理预演结果与清理清单一致。
7. 后端高风险文件已经独立决策。
