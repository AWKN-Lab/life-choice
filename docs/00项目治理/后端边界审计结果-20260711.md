## 二、硬阻断项

### BLOCK-01｜ConsultDialogueTurn 迁移与 Schema 冲突

证据：

- 迁移存在：`20260703183000_add_consult_dialogue_turn/migration.sql`
- 当前 `schema.prisma` 缺少 `model ConsultDialogueTurn`
- 产品 PRD、数据库基线和工程文档仍将该模型定义为多轮对话资产

处理：

- 恢复模型；或
- 建立正式能力下线决策、反向迁移、代码删除和数据处置方案

当前禁止直接提交 Schema 删除。

### BLOCK-02｜lastAccessedAt 代码引用与 Schema 冲突

证据：

- `memory-forget.service.ts` 多处查询和更新 `lastAccessedAt`
- 迁移存在：`20260703183500_add_memory_last_accessed_at/migration.sql`
- 当前 `schema.prisma` 缺少字段与索引
- 生产历史日志已出现 `Unknown argument lastAccessedAt`

处理：

- 恢复字段与索引；或
- 同步移除遗忘衰减服务中的全部引用，并重新评审产品能力

### BLOCK-03｜MemoryEmbedding 代码引用与 Schema 冲突

证据：

- `memory-embedding.service.ts` 使用 `prisma.memoryEmbedding`
- `orchestrator.module.ts` 注册 `MemoryEmbeddingService`
- `user-memory.service.ts` 调用向量检索能力
- 迁移存在：`20260703184000_add_memory_embedding/migration.sql`
- 当前 `schema.prisma` 缺少 `model MemoryEmbedding`

处理：

- 恢复模型；或
- 同步删除服务、模块注册、调用链、迁移和 PRD 能力定义

```text

```

### 结构判断

当前形成两套依赖边界：

1. 后端根：PM2 启动器与一套完整后端依赖
2. API Server：CI、构建、测试和生产安装依赖

两套依赖清单长期漂移，已形成不可预测的运行时解析结果。
