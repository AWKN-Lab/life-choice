## 五、已识别的工程风险

### 后端包管理

当前存在：

- 后端根 `package-lock.json`
- API Server `package-lock.json`
- 后端根 `yarn.lock`
- README 中的 pnpm 安装口径
- 生产部署中的 npm 口径

三份锁文件同步出现大规模变化。正式收口前需要确认唯一包管理器和唯一安装目录。

### 构建链

后端根 `build` 命令取消了资产复制与构建验证。`assets-manifest.json` 同时删除知识绑定文件。该变化需要独立验证。

### Prisma Schema

当前工作区删除了 `ConsultDialogueTurn`、`MemoryEmbedding`、`lastAccessedAt` 和相关索引。该变化需要生产数据库取证、引用扫描、Prisma 校验和回滚方案。

详细记录：`后端包管理与Schema风险-20260711.md`。
